RP-0007 / ongoing cycle

雨が種に触れるまで

ORIGINAL LANGUAGE / AREM

掌の種が、雨を待つあいだに現在・内在・欠如・接近を通り、最後に子どもの手と雨の接触へ戻る。

A — AREME — ENV — VELA

A / original

アレム語

I — 掌

原詩
逐語訳

V — 雨

原詩
逐語訳
Garan na kat.

現在相の雨｜接触している｜現在相の種

日本語で読む

種は掌にあり、子どもと雨はまだそこへ近づいている。内側へ沈んだ種には、夜明けがさらに内側から含まれている。

雨が来なかった可能性を通過すると、種も手も朝も欠如へ落ちる。それでも互いへ近づき直し、最後に雨が種へ触れる。

新語根 g-r-n は種・穀粒。芽吹く動詞や未来形を作らず、母音相だけで潜在・欠如・接近を表す。

na から読む

雨が静かに休む。窓の向こうで朝が開き、カーテンの後から鳥が戻って歌う。

tu から読む

鳥が戻って歌う。その帰還の後で雨は静かに休み、窓と朝が開いていく。

日本語で読む

アレム語で種が担った潜在生命を、エン語では「休んでいるもの」と「戻る鳥」の順序へ移す。

雨から始めれば朝が帰還を生み、鳥から始めれば帰還が朝を開く。新しい語対は使わない。

V / translation

ヴェラ語

表層詩

原詩
逐語訳
nami sera toku
名｜手｜眠る、静止している
nave lori mase
雨｜静かに休む｜窓
keno vari sume
朝｜開く｜カーテン

名は手の中で眠っている。雨は窓辺で静かに休む。朝が布を開く。

発声

namiseratoku → namise / ratoku
navelorimase → navelo / rimase
kenovarisume → kenova / risume
発声音列
逐語訳
namise / ratoku
手だけが覚えている｜声が忘れたもの
navelo / rimase
死者たちが戻る｜顔を持たずに
kenova / risume
あなたの名は失われた｜それでも返事をする

日本語で読む

表層では、手の中で眠る名、休む雨、開く朝。発声すると、手だけが覚えているもの、顔を持たず戻るもの、失われても返事をする名へ変わる。

アレム語の種の欠如と帰還を、ヴェラ語では名と記憶の欠如・帰還へ分けた。三行とも既存語彙のみ。
