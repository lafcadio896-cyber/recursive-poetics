石が水の記憶を離れる

ORIGINAL LANGUAGE / AREM

雨のあとの水辺で、石が水の内在から離れ、子どもの手の現在へ移る。

A — AREME — ENV — VELA

日本語で読む

石は水に触れ、雨を受ける。やがて石は水の記憶の内部に入り、海から遠ざかり、一度は失われた海の後ろへ残される。

それでも石は子どもへ近づき、ふたたび手に触れられる現在になる。夜明けだけが水の上に残る。

新語根 k-r-s は石を不変の物質ではなく、水と手のあいだで存在距離を変える大地の断片として扱う。

日本語で読む

手の中にあるものは声になり、家に残る。息は境界の後ろで失われ、戻ったものは光となって水面に触れ、記憶となり、名として再び手へ閉じる。

アレム語の「石が海から手へ移る」という距離変化を、「手→喪失→帰還→水面→記憶→名」という輪へ変えた。

V / translation

ヴェラ語

表層

原詩
逐語訳
mora seyo ratu
月｜見る・視線を向ける｜海
ratu vame nika
海｜覚えている｜記憶の中の子ども

開いた扉｜夜明け｜子ども

発声

moraseyoratu → morase / yoratu
ratuvamenika → ratuva / menika
kesumeyokali → kesume / yokali

朝が来た後で月が沈む。海は、まだ起きていないことを覚えている。夜明けが戻るのは、子どもがそれを開いたからだ。

日本語で読む

表層では月と海と子どもが静かに並ぶ。発声すると、海が未来を記憶し、夜明けの帰還が子どもの行為と結びつく。

石そのものは保存せず、物体の移動を「海がまだ起きていないことを覚えている」という時間のずれへ変換した。
