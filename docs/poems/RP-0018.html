RP-0018 / ongoing cycle

手だけが、まだ一人になっていない

ORIGINAL LANGUAGE / VELA

伴侶を失った後、理解は一人になったことを受け入れているのに、身体だけが二人分を整え続ける。

日本語で読む

あなたの名は、二人分を整える手つきの中に残った。

一人になったことを、私はもう知っている。それでも器を置くたび、手だけが、まだ知らない。

空白を消すと「名が残る」から「手だけが日課を覚えている」へ変わる。同じ行を二度読むが、二度目はもう同じ意味には戻らない。

日本語で読む

死者のあとに残ったのは、思い出だけではなかった。名は手の内側に入り、その手は死の後にも残った。

そして今日の手として、また同じ順序を始める。

ヴェラ語の「理解と身体のずれ」を、内在相の手が現在相へ戻る距離変化へ置き換えた。死者は戻らないが、その人と暮らした手だけが現在へ戻ってしまう。

日本語で読む

なくしたものは、なくしたままではいてくれない。名になって手へ戻り、手から声へ、声から家へ移っていく。

だから私は、忘れたのではなく、毎日ちがう場所であなたを思い出す。

ヴェラ語の同一行反復を、エン語では「喪失から名へ、名から手へ戻る輪」として翻訳した。習慣は、失ったものが毎回手へ戻る循環として現れる。

LEARNING APPENDIX

今回覚えられる語彙

今回の新語はヴェラ語2件。物体名ではなく、共同生活が身体に残した人数感覚と日課を表す。

ヴェラ語

語意味
seramo二人分を当然のように整える手つき。人数が一人になった後にも、身体が二人分の配置を先に作ってしまう習慣。
ramomado戻らない者の分を、もう戻らないと知った後にも用意し続ける日課。理解より遅れて身体に残る共同生活の癖。

nami + seramo + mado = namiseramomado = namise + ramomado。音の追加・削除はなく、境界だけが移動する。
