RP-0019 / ongoing cycle

名の届かない未来へ、仕事だけが残る

ORIGINAL LANGUAGE / AREM

死者の名が次の世代へ届かなくても、その人の仕事・手入れ・技だけは別の手へ受け継がれて効き続ける。

A — AREME — ENV — VELA

A / original

日本語で読む

死者のあとに、仕事が残る。名は、子どもへ届かない。

それでも仕事の内側にあった種は、その子どもに触れる。名を知らない手の内側へ、仕事だけが入っていく。

人は、自分の名が届かない未来にも、仕事だけを届かせることがある。

新語根 f-r-t は、行為者の名や生が届かなくなった後にも、別の人の手を通して効き続ける仕事・手入れ・技の残効を表す。farat → firit → farat と、仕事だけが現在から他者の身体内へ入り、再び現在へ現れる。

日本語で読む

誰のものだったかを知らないまま、手は先に受け取っている。声になり、家に残り、いちど失われても、別の形で戻ってくる。

記憶が名になるのは、いつも手に入った後だ。

アレム語では名が届かず仕事だけが残る。エン語では、手に入ったものが後から名へ変わるため、継承の順番そのものが反転する。

逐語訳
namiseratoku → namise / ratoku
手だけが覚えている｜声が忘れたもの
miramorenalu → miramo / renalu
昼の光が描く｜羽のない空所

日本語で読む

表層では、名は手の中で眠り、明かりが屋根を描く。

声にすると、声が忘れたものを手だけが覚えている。昼の光は、もう誰のものでもない空所の形だけを描く。

アレム語の「名より長く働く仕事」を、ヴェラ語では「声が忘れても手が覚える」という忘却速度の差へ変形した。
