RP-0020 / ongoing cycle

抱けなくなっても、手は昔の重さを捨てない

ORIGINAL LANGUAGE / EN

成長してもう抱き上げられなくなった子の現在の身体と、親の手が覚えている「最後に抱けた重さ」のずれ。

E — ENA — AREMV — VELA

全隣接語対

語対

名

自然な日本語訳

もう抱き上げられないほど、あなたは大きくなった。

それでも私の手は、あなたを軽く覚えている。

見間違えているのではない。手の中には、最後に抱けた日の重さが残っている。

子どもは大きくなる。親の手だけが、その人の昔の大きさを捨てない。

日本語で読む

moravel と sela 単独には意味がない。三つの新しい境界だけが、最後に抱けた重さ、現在との同一性、内側の呼び名を作る。

no ta の名から ta ku の手へ輪が戻るため、昔の大きさは現在の呼び名を経て再び手の中へ入る。

翻訳では「重さ」そのものを保存せず、アレム語では存在距離へ、ヴェラ語では声と手の記憶差へ変形する。

自然な日本語訳

いまのあなたは、私の手に触れている。けれど、抱き上げられる距離からはもう遠ざかった。

それでも手の内側には、小さかったあなたがいる。その内側には、いま呼ぶ名まで残っている。

遠ざかったのは子どもではなく、抱き上げられる距離の方だった。

翻訳による変形

k-l を現在相 kal、離行相 kol、内在相 kil へ動かし、成長を「手からの距離」に置き換える。

子どもそのものは欠如相へ行かない。抱けなくなっても、手の内側の子どもは残る。

ヴェラ語

表層

表記
逐語訳
nami sera toku
名｜手｜眠る・静止している

発声

発声音列
逐語訳
namiseratoku → namise / ratoku
手だけが覚えている｜声が忘れたもの

自然な日本語訳

表層：あなたの名は、手の中で眠っている。

発声：声ではもう言い分けられない昔のあなたを、手だけが覚えている。

翻訳による変形

原詩の「昔の重さ」を直接語彙化せず、表層の名と、発声側の身体記憶へ分ける。

nami + sera + toku = namiseratoku = namise + ratoku。音は増減せず、境界だけが変わる。
