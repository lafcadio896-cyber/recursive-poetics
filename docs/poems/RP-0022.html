RP-0022 / ongoing cycle

子どものまま、手の向きだけが変わる

ORIGINAL LANGUAGE / AREM

育てられた者が初めて育てた者を支える日、親子という関係は終わらず、支える手の向きだけが反転する。

A — AREME — ENV — VELA

A / original

アレム語

原詩

原詩
逐語訳

接近相の支え方向の反転｜近づいていく｜現在相の子ども

現在相の子ども｜接触している｜現在相の支え方向の反転
Kat na kal.
現在相の手｜接触している｜現在相の子ども

日本語で読む

親を支えた日、子どもを卒業したのではない。

子どものまま、手の向きだけが変わった。その向きは一度変わると手の内側に残る。

pelem → palam → pilim と反転だけが接近・現在・内在へ移り、子ども kal は現在相のまま残る。

日本語で読む

役割の名より先に、手が動くことがある。支えたあとで、ようやく自分が支える側へ回ったのだと分かる。

アレム語の関係反転を、名と手が一周する順序へ変換した。名は固定された身分ではなく、手へ戻るたび意味を持ち直す。

日本語で読む

名は変わらない。けれど呼び方では分からなくなった変化を、手だけが覚えている。

昨日まで支えられていた手が、今日は誰かを支えていることを。

アレム語では反転を名づけるが、ヴェラ語ではその名前を消し、身体にしか残らない知識へ変える。
