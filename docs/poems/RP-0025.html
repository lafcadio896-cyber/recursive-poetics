RP-0025 / ongoing cycle

家は小さくならなかった

ORIGINAL LANGUAGE / AREM

長く離れた家へ帰ると、昔より狭く感じる。変わったのは家ではなく、旅のあいだに変わった自分の身体尺度だった。

A — AREME — ENV — VELA

A / original

アレム語

日本語で読む

家は、出ていった日の戸口のままだった。

帰るほど、家が小さくなっていく気がした。

戸口に手を置いて、やっと分かった。家が縮んだのではない。遠くで暮らすあいだに、こちらの歩幅が変わっていた。

帰ったあと、その狭さだけが手の内側に残る。家は最後まで、同じ戸口のままだった。

翻訳による変形

新語根 b-r-k は、帰還時にだけ露呈する「記憶していた場所の尺度」と「現在の身体尺度」のずれを表す。

berek → barak → birik とずれだけが接近・現在・内在へ移り、家 lam と扉 dar は最初から最後まで現在相のまま動かない。

場所は変わらない。変わった身体だけが、帰った場所を狭く感じる。

ve から読む

家に残るものから始める。息は扉の後ろへ入り、いったん失われる。戻ってきたものは光と接触を通り、記憶になり、名になり、手と声を経て、ふたたび家に残る。

re から読む

最初に「戻ってくる」がある。戻ったものはすぐ家へ着くのではなく、光、水面、記憶、名、手、声を通った後に初めて「家に残る」へ到達する。

日本語で読む

帰ることは、戸口を越えることだけではない。

戻ってきた者は、光に触れ、記憶に触れ、昔の名を手に取って、もう一度その家の声になる。

家が先に待っていたのか、帰った者が後から家を作り直したのか。輪には、最初の場所がない。

アレム語の「場所と身体尺度のずれ」を、帰還者が家へ再接続されるまでの関係の長さへ変えた。

黙読

表層
逐語訳
mare lino saku
光｜水・水面｜触れる

光が水面に触れる。水は、来たものと同じ光を返しているように見える。

発声

marelinosaku → mareli / nosaku
発声
逐語訳
mareli / nosaku
誰かが呼ぶ｜消された名前

誰かが呼ぶ。もう使われなくなった名を。

帰ってきた者は振り向く。その名で振り向ける自分が、まだどこかに残っていたことに驚く。

翻訳による変形

表層では水面が同じ光を返す。発声すると、同じ場所が昔の自己を「消された名」で呼び戻す。

marelinosaku は表層 mare / lino / saku と発声 mareli / nosaku で文字列が完全一致する。

変わらない場所の裏から、現在の自分には少し合わなくなった古い名が聞こえる。
