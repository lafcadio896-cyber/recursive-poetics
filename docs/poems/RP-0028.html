RP-0028 / ongoing cycle

暗くなる前に、身体は帰り道を覚える

ORIGINAL LANGUAGE / AREM

何度も通った帰り道は、光や目印が失われても身体の内側に残り、家が見えるより先に次の進路を選ばせる。

A — AREME — ENV — VELA

日本語で読む

日が落ちて、道の形が見えなくなる。

それでも身体は、曲がる少し前からもう曲がり始めている。

家が見えるより先に、帰り方のほうがこちらへ近づく。

何度も帰った道は、いつの間にか外の地面から息の内側へ移っていた。

翻訳による変形

新語根 t-l-m は道そのものではなく、見えないときにも身体が進路を先取りする感覚を表す。

talam → tilim → tulum → telem → talam と母音相を移し、外部の経路が身体内部へ移り、欠如を通って家へ接触する。

帰る主体が道を探すのではなく、身体の内側へ移った道が家へ近づいていく。

日本語で読む

見えなくなったものは、なくなったとは限らない。

扉の向こうで失われた道順が、記憶になり、手の中へ入り、家に残る。

帰るとき、身体は地面より先にその輪を読み始める。

翻訳による変形

アレム語では「道が身体の内側へ移る」。エン語では道という概念を消し、喪失したものが記憶・手・声・家を一周することで、身体化された帰路を関係の輪へ変える。

namise / ratoku

日本語で読む

表層では、名は静かな手の中で眠っている。

発声すると、手だけが覚えている。声が忘れたものを。

道の名を言えなくても、暗いところで身体は次の曲がり方を知っている。

翻訳による変形

表層 nami / sera / toku の連続音列は、発声時に既存語 namise / ratoku へ完全一致して再分節される。

帰路を直接言わず、声から消えた知識と手に残った知識の落差として示す。
