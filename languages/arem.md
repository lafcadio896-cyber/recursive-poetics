# アレム語 — Arem

## 核心

アレム語では、**子音骨格が概念**を、**母音がその概念との距離・存在状態**を表す。

同じ子音骨格を保ったまま母音を変えることで、対象そのものではなく、対象が話者にとってどこにあるかが変化する。

## 母音相

| 母音 | 相 | 意味 |
|---|---|---|
| `a` | 現在相 | いまここにあり、触れられる |
| `i` | 内在相 | 記憶・身体・内部にある |
| `o` | 離行相 | 遠ざかり、終わりつつある |
| `u` | 欠如相 | 失われ、届かず、存在が疑われる |
| `e` | 接近相 | 近づき、戻ろうとしている |

例：子音骨格 `m-r` は「光」。

- `mar` — いまここにある光
- `mir` — 記憶の内部にある光
- `mor` — 遠ざかる光
- `mur` — 届かない光
- `mer` — 近づいてくる光

## 統語

基本語順は以下。

```text
主語　関係語　目的語
```

関係語も距離や方向を担う。

- `na` — 接触している、上にある
- `vi` — 内部にある
- `ra` — 離れていく
- `do` — 後ろに残る
- `ve` — 近づいていく

## 語形成

短い二子音語根だけでなく、三〜四子音の拡張語根を許可する。拡張語根では、同じ母音相を各子音間に反復して語形を作る。

例：`s-k-r` が「影」である場合。

- `sakar` — 現在の影
- `sikir` — 内在する影
- `sokor` — 遠ざかる影
- `sukur` — 失われた影
- `seker` — 近づく影

派生接頭辞は語根の基本概念を変更せず、概念に一定の方向を加える。接頭辞と語幹の境界は辞書ではハイフンで示し、本文では融合形を使用してよい。

| 接頭辞 | 機能 | 説明 |
|---|---|---|
| `in-` | 内包 | 内側に隠す、包み込む |
| `ex-` | 外化 | 外へ出す、露出させる |
| `re-` | 回帰 | 戻す、再び行う |
| `con-` | 結合 | 複数を一つのまとまりとして扱う |
| `non-` | 意味否定 | 概念そのものを否定する |

`non-` と欠如相 `u` は異なる。`non-mar` は「光ではないもの」、`mur` は「光であるが届かないもの」である。

接辞付き語も母音相を保持する。

- `remar` — 戻ってきた現在の光
- `remir` — 記憶内へ戻った光
- `remur` — 戻るはずだったが届かない光

新しい派生語を使う場合は、基礎語根、接辞、母音相、合成後の語義を辞書へ記録する。

## 詩における制約

1. 一篇の中で主要語根を反復する。
2. 母音相の変化そのものを時間・記憶・喪失として読めるようにする。
3. 日本語訳では、単語の意味だけでなく距離相を明示する。
4. `a → i → o → u → e → a` は基本的な帰還形だが、必須ではない。
5. 同じ `a` に戻っても、喪失を通過した後の現在は最初の現在と同一ではない。
6. 一篇の語形を三文字語だけで均一化しない。短語、拡張語根、派生語を混在させる。
7. 新語は既存語根からの派生を優先し、完全な新語根は必要な場合だけ追加する。

## 翻訳原則

他言語からアレム語へ訳す際は、原詩の出来事を一列に並べるのではなく、**何が近づき、何が内部化され、何が失われるか**を選び直す。
