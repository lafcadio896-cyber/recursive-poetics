# エン語 — En

## 核心

エン語では、**単独の語には固定された意味がない**。隣り合う二語の組だけが意味を持つ。

```text
ka lin mo se
```

この語列では、`ka` や `lin` は単独では無意味であり、`ka lin`、`lin mo`、`mo se` という境界にだけ語義が生じる。

## 環状文

詩は原則として輪を作る。末尾と先頭も隣接しているため、最後の組も意味を持つ。

```text
ka lin mo se ka
```

同じ輪でも、どこを先頭として提示するかによって、読者が最初に受け取る出来事と因果関係が変わる。

## 基本規則

1. 語は一〜三音節とし、短語・中語・長語を混在させる。
2. 語義辞典には単語ではなく、順序付きの語対を登録する。
3. `ka lin` と `lin ka` は別の意味でよい。
4. 一つの語は、左隣との組と右隣との組で異なる役割を持つ。
5. 詩から一語を消すと、消された語の両隣が初めて接触し、新しい意味が発生する。

## 関係接辞

エン語では語幹単独に固定語義を与えないが、接辞は語対の読み方を制御する文法的な働きを持つ。接辞付き語も、それ単独では名詞や動詞の意味を持たない。

| 接辞 | 操作 | 語対への効果 |
|---|---|---|
| `in-` | 反転 | 接辞付き語から次の語へ向かう関係を否定・反転する |
| `re-` | 回帰 | 直前に成立した関係を再び呼び戻す |
| `con-` | 結合 | 左右二つの関係を一つの集合として読む |
| `ex-` | 分離 | 次の関係を外へ放つ、切り離す |
| `sub-` | 潜在 | 表面上の関係の下に別の関係があることを示す |

例として `lin mora` が「月を待つ」で登録されている場合、`lin inmora` は自動的に「月を待たない」にはならない。`lin inmora` という接辞付き語対を辞書へ登録し、反転前の語対との関係を説明する必要がある。

接辞は意味生成の規則であり、辞書登録を省略するための万能変換ではない。使用した接辞付き語対はすべて登録する。

## 長語形成

語幹は一〜三音節を許可し、次の形を混ぜる。

- 短語：`ma`、`tu`
- 中語：`rilan`、`seno`
- 長語：`moravel`、`conarim`

長い語は単独で意味を持つように見えても、実際の意味は隣接語対にのみ生じる。この外見と構造のずれをエン語の特徴として利用する。

同じ詩で全語を二文字に揃えない。少なくとも一つは四文字以上の語を含め、新語導入時は既存の音節列と衝突しないことを確認する。

## 読み方

### 始点読み

輪の始点を変更する。語対の集合は同じだが、提示順により物語の因果が変わる。

### 歩幅読み

一語ずつではなく、一定の歩幅で輪をたどる。たとえば一語飛ばしで読むと、通常読みとは別の語対列を作れる。

### 欠落読み

一語を削除して読む。失われたもの自体ではなく、**喪失によって初めて隣り合った二者**が新しい意味を作る。

## 詩における制約

- 少なくとも一周したとき文意が閉じること。
- 始点を変えた日本語訳を二種類以上示すこと。
- 読者が任意の始点を選べるよう、原文は一行の輪としても掲示すること。
- 通常読みで使用した全隣接語対を登録すること。
- 欠落読み・歩幅読みの一時語対も作品内と辞書に記録すること。
- 新語は既存語対の一部を接辞化・長語化して派生させる方法を優先する。

## 翻訳原則

他言語からエン語へ訳す際は、出来事を保存するのではなく、**どの二項関係を輪として保存するか**を選ぶ。時間の推移は、始点・歩幅・欠落によって再現する。
