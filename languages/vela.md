# ヴェラ語 — Vela

## 核心

ヴェラ語では、同じ音列が**黙読時と朗読時で異なる境界に分割される**。

紙面上では穏やかな風景詩として読めるが、声に出して連結すると別の語群が現れ、隠されていた詩になる。

```text
nave lori mase
```

黙読では三語。

```text
nave / lori / mase
```

朗読では空白を消し、別の位置で切る。

```text
navelo / rimase
```

## 二つの辞書

ヴェラ語には、同じ音列を共有する二つの辞書がある。

- **表層辞書** — 紙面上の空白に従って読む語彙
- **発声辞書** — 連続音声を再分節して読む語彙

両者の意味は直接対応しなくてよい。ただし、発声側は表層側の風景を否定するだけでなく、なぜその風景が書かれたかを照らす内容にする。

## 基本規則

1. 表層文の各行は二〜四語程度とする。
2. 朗読時には行内の空白を無視する。
3. 発声側の分節は表層側と少なくとも一箇所ずらす。
4. 発音は同一であり、演者が音を追加・削除してはならない。
5. 行末の休止は保ってよい。行を越えた再分節は上級的な用法とする。
6. 短語・中語・長語を混在させ、各語を同じ長さへ揃えない。

## 接辞と長音列

ヴェラ語では、接辞は表層側では一定の意味を持つが、発声側では必ずしも同じ接辞として残らない。接辞の音が隣接語へ取り込まれ、別の発声語を作ってよい。

| 表層接辞 | 表層での機能 |
|---|---|
| `in-` | 内側、隠された状態 |
| `re-` | 戻る、繰り返す |
| `ne-` | 否定、不在、欠落 |
| `co-` | 結合、共在 |
| `ex-` | 外側、放出、離脱 |

例：

```text
表記：re-nave lori
連音：renavelori
発声：renavi / lori
```

この場合、表層の `re-` は「戻る雨」を作るが、発声側では `renavi` という別語の一部となる。表層接辞の意味を発声側へそのまま持ち込んではならない。

接辞付き表層語と、それを含む発声語は両方とも辞書登録する。音列一致を優先し、意味の対応は詩の構造として説明する。

長語は七〜十文字程度まで許可する。ただし、一語が長くなりすぎて再分節箇所が一つしかなくなる場合は避ける。少なくとも二通り以上の自然な境界候補を持つ音列を優先する。

## 記法

作品では以下を併記する。

```text
表記：nave lori mase
連音：navelorimase
発声：navelo / rimase
```

接辞付き語では、辞書にだけ形態境界を示し、本文では通常の綴りへ融合してよい。

```text
辞書：re-nave
本文：renave
```

## 詩における制約

- 表層詩だけでも一篇として成立させる。
- 発声詩だけでも一篇として成立させる。
- 二篇を知った後、表層詩の語彙が別の意味に見え始めるようにする。
- 最初と最後に同じ音列を置く場合、二度目は同じ意味に戻らない。
- 新語は、表層語と発声語を対で設計する。
- 新しい接辞付き語を使う場合、接辞・基礎語・融合形・発声側の再分節をすべて説明する。

## 翻訳原則

他言語からヴェラ語へ訳す際は、原詩をそのまま表層側へ移さない。原詩の明示された内容を一方へ、隠された前提・否認・原因をもう一方へ割り当て、**二つの詩の落差**として再構成する。
