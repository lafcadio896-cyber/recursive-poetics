# 語彙集

このディレクトリは、三つの架空言語で実際に使用された語彙を蓄積する。

目的は、読者が日本語訳を見なくても、既知の語彙と文法から詩を部分的または完全に読めるようになることである。

## 基本方針

1. 新しい作品は、まず既存語彙を再利用する。
2. 新語を使った場合は、作品の追加と同時に対応する語彙集へ登録する。
3. 一度確定した語義は、原則として変更しない。
4. 同じ語形・語根・語対に別の意味を与えない。
5. 多義語を作る場合は、偶然の衝突ではなく、意味の派生関係を明記する。
6. 過去作品に矛盾が見つかった場合は、削除して隠さず「旧用法・衝突」として記録し、後から改訂する。

## 言語ごとの登録単位

- [アレム語](arem.md)：子音語根、母音相、関係語
- [エン語](en.md)：単語ではなく、順序付きの語対
- [ヴェラ語](vela.md)：表層語と発声語を分けて登録

## 作品生成時の必須処理

新しい相互翻訳詩を生成するときは、以下を同じコミットで行う。

- 三言語の語彙集を先に読む
- 使用語彙を既存語彙と照合する
- 新語を語彙集へ追記する
- 語義衝突があれば作品を公開しない
- 各作品末尾に「今回使用した語彙」を掲載する

語彙集が言語の記憶であり、作品本文はその時点での使用例となる。
