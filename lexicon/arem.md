# アレム語語彙集

アレム語では、子音骨格が概念を、母音がその概念との距離・存在状態を表す。

## 母音相

| 母音 | 相 | 意味 |
|---|---|---|
| `a` | 現在相 | いまここにあり、触れられる |
| `i` | 内在相 | 記憶・身体・内部にある |
| `o` | 離行相 | 遠ざかり、終わりつつある |
| `u` | 欠如相 | 失われ、届かず、存在が疑われる |
| `e` | 接近相 | 近づき、戻ろうとしている |

## 正規語根

| 子音骨格 | 基本概念 | 使用例 |
|---|---|---|
| `m-r` | 光 | `mar` 現在の光 / `mur` 届かない光 |
| `s-l` | 水、水面 | `sal` 現在の水 / `sil` 記憶の水 |
| `n-l` | 名、呼ばれること | `nal` 現在の名 / `nul` 呼べない名 |
| `k-t` | 手、接触する身体 | `kat` 現在の手 / `kut` 触れられない手 |
| `v-l` | 声 | `val` 現在の声 / `vul` 聞こえない声 |
| `l-m` | 家、帰る場所 | `lam` 現在の家 / `lum` 帰れない家 |
| `h-r` | 息、呼吸 | `har` 現在の息 / `hur` 失われた息 |
| `d-r` | 扉、境界 | `dar` 現在の扉 / `dur` 開かない扉 |
| `n-v` | 雨 | `nav` 現在の雨 / `nuv` 存在しない雨 |
| `m-s` | 窓 | `mas` 現在の窓 / `mus` 存在しない窓 |
| `t-r` | 鳥 | `tar` 現在の鳥 / `tur` 届かない鳥 |
| `r-f` | 屋根 | `raf` 現在の屋根 / `ruf` 失われた屋根 |

## 関係語

| 語 | 意味 |
|---|---|
| `na` | 接触している、上にある |
| `vi` | 内部にある |
| `ra` | 離れていく |
| `do` | 後ろに残る |
| `ve` | 近づいていく |

## 旧用法・衝突

初期作品には、辞書を固定する前に作られたため、正規語根と衝突する用法がある。

| 語根 | 旧用法 | 問題 |
|---|---|---|
| `m-r` | 夜明け | 正規語義「光」と衝突 |
| `s-l` | 子ども | 正規語義「水」と衝突 |
| `p-r` | 鳥 | 正規語義 `t-r` と重複 |

これらは今後使用しない。該当する初期作品は、意味を保ったまま正規語彙へ改訂する予定とする。

## 読み方の例

`Tor ra raf.`

- `t-r` = 鳥
- `o` = 離行相
- `ra` = 離れていく
- `r-f` = 屋根
- `a` = 現在相

したがって、「遠ざかる鳥が、現在の屋根から離れていく」と読める。
