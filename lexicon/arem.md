# アレム語語彙集

アレム語では、**子音骨格が基本概念**を、**母音がその概念との距離・存在状態**を表す。

語形は短い二子音語根だけでなく、三〜四子音の拡張語根と接辞付き派生語を許可する。大文字・小文字は文頭表記の差であり、語義には影響しない。

## 母音相

| 母音 | 相 | 意味 |
|---|---|---|
| `a` | 現在相 | いまここにあり、触れられる |
| `i` | 内在相 | 記憶・身体・内部にある |
| `o` | 離行相 | 遠ざかり、終わりつつある |
| `u` | 欠如相 | 失われ、届かず、存在が疑われる |
| `e` | 接近相 | 近づき、戻ろうとしている |

## 正規語根

同じ子音骨格を、別の基本概念に再利用してはならない。

| 子音骨格 | 基本概念 | 使用例 |
|---|---|---|
| `m-r` | 光 | `mar` 現在の光 / `mur` 届かない光 |
| `s-l` | 水、水面 | `sal` 現在の水 / `sil` 記憶の水 |
| `n-l` | 名、呼ばれること | `nal` 現在の名 / `nul` 呼べない名 |
| `k-t` | 手、接触する身体 | `kat` 現在の手 / `kut` 触れられない手 |
| `v-l` | 声 | `val` 現在の声 / `vul` 聞こえない声 |
| `l-m` | 家、帰る場所 | `lam` 現在の家 / `lum` 帰れない家 |
| `h-r` | 息、呼吸 | `har` 現在の息 / `hur` 失われた息 |
| `d-r` | 扉、境界 | `dar` 現在の扉 / `dur` 開かない扉 |
| `n-v` | 雨 | `nav` 現在の雨 / `nuv` 降らなかった雨 |
| `m-s` | 窓 | `mas` 現在の窓 / `mus` 存在しない窓 |
| `t-r` | 鳥 | `tar` 現在の鳥 / `tur` 届かない鳥 |
| `r-f` | 屋根 | `raf` 現在の屋根 / `ruf` 失われた屋根 |
| `m-n` | 月 | `man` 現在の月 / `mun` 失われた月 |
| `s-r` | 海 | `sar` 現在の海 / `sur` 失われた海 |
| `k-l` | 子ども | `kal` 現在の子ども / `kul` 失われた子ども |
| `y-r` | 夜明け、朝の到来 | `yar` 現在の夜明け / `yur` 来なかった夜明け |
| `d-t` | 死者、死んだ者 | `dat` いまここにいる死者 / `det` 近づく死者 |
| `g-r-n` | 種、穀粒、芽吹きうるもの | `garan` 現在の種 / `girin` 内に保持された種 / `gurun` 届かない種 / `geren` 現れようとする種 |
| `k-r-s` | 石、岩片、手で触れられる大地の断片 | `karas` 現在の石 / `kiris` 記憶・内部の石 / `kurus` 失われた石 / `keres` 近づく石 |
| `f-r-t` | 行為者の名や生が届かなくなった後にも、別の人の手を通して効き続ける仕事・手入れ・技の残効 | `farat` いま働いている継承仕事 / `firit` 別の手の内側へ取り込まれた仕事 / `furut` 誰にも届かなくなった仕事 / `feret` 新しい担い手へ近づく仕事 |
| `p-l-m` | 育てられた者が初めて育てた者を支える側へ回るときに生じる、親子間の支援方向の反転。親子関係の終了や介護一般は指さない | `palam` 現在の反転 / `pilim` 身体に内在した反転 / `pelem` 近づく反転 |
| `b-r-k` | 長く場所を離れた者が帰還したとき、記憶していた場所の尺度と現在の自分の身体尺度が一致しないことで生じるずれ | `barak` 現在のずれ / `birik` 身体に内在したずれ / `berek` 近づくずれ |

`g-r-n` は `RP-0007 雨が種に触れるまで` で初出。播かれる前・芽吹く前も同じ語根を保ち、母音相によって「触れられる種」「内部に保持された種」「失われた可能性としての種」「現れようとする種」を区別する。

`k-r-s` は `RP-0010 石が水の記憶を離れる` で初出。石そのものの材質ではなく、水や手との関係の中で位置を変える「大地の断片」を基本概念とする。`karas / kiris / koros / kurus / keres` の五相を持つ。

`f-r-t` は `RP-0019 名の届かない未来へ、仕事だけが残る` で初出。単なる職業や作業を指さず、作った者・教えた者の名が次の世代へ届かなくても、手入れ・技・働きの結果だけが別の身体へ受け継がれて効き続けることを基本概念とする。`farat / firit / forot / furut / feret` の五相を持つ。

`p-l-m` は `RP-0022 子どものまま、手の向きだけが変わる` で初出。育てられた側が初めて育てた側を支える瞬間に生じる「支えの方向の反転」を基本概念とし、介護一般や親子という身分そのものは指さない。`palam / pilim / polom / pulum / pelem` の五相を持つ。

`b-r-k` は `RP-0025 家は小さくならなかった` で初出。長く離れた場所へ帰ったとき、家そのものは変わっていなくても、記憶していた場所の尺度と現在の身体尺度が一致しないことで生じる帰還時のずれを基本概念とする。単なる狭さ、成長、郷愁は指さない。`barak / birik / borok / buruk / berek` の五相を持つ。

## 正規接辞

接辞は語根の基本概念を置き換えず、概念へ一定の方向を加える。実際に使った派生形は別途登録する。

| 接辞 | 機能 | 説明 |
|---|---|---|
| `in-` | 内包 | 内側へ隠す、包み込む |
| `ex-` | 外化 | 外へ出す、露出させる |
| `re-` | 回帰 | 戻す、再び行う |
| `con-` | 結合 | 複数を一つのまとまりとして扱う |
| `non-` | 意味否定 | 概念そのものを否定する |

`non-` は欠如相 `u` と同義ではない。`non-mar` は「光ではないもの」、`mur` は「光であるが届かないもの」。

## 拡張語根の形成

三子音語根 `C1-C2-C3` は、同じ相母音を反復して `C1VC2VC3` とする。

例：`g-r-n` = 種の場合、`garan / girin / goron / gurun / geren` の五相を作る。

未登録の拡張語根を本文だけで使用してはならない。

## 派生語

派生語は初出作品ごとに、基礎語、接辞、相、派生語義を記録する。現在、正式登録済みの派生語はない。

## 関係語

関係語は母音相を持たない独立語である。

| 語 | 意味 |
|---|---|
| `na` | 接触している、上にある |
| `vi` | 内部にある、記憶の中にある |
| `ra` | 離れていく |
| `do` | 後ろに残る |
| `ve` | 近づいていく |

## 廃止語根

以下は辞書固定前の初期稿で使われたが、正規化によって廃止した。現在の作品本文には使用しない。

| 子音骨格 | 旧用法 | 正規形 |
|---|---|---|
| `p-r` | 鳥 | `t-r` |
| `m-r` | 夜明け | `y-r` |
| `s-l` | 子ども | `k-l` |

廃止語根は歴史記録であり、翻訳時の候補には含めない。

## 読み方の例

`Yur do tur.`

- `y-r` = 夜明け
- `u` = 欠如相
- `do` = 後ろに残る
- `t-r` = 鳥
- `u` = 欠如相

したがって、「来なかった夜明けが、届かない鳥の後ろに残る」と読める。
