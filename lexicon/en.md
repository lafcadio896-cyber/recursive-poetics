# エン語語彙集

エン語では、単独の語に固定された意味はない。意味を持つのは、左から右へ並んだ二語の組だけである。

`ka lin` と `lin ka` は別の語彙として扱う。

## 正規語対

### 『帰光』系

| 語対 | 意味 |
|---|---|
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |

### 『始点のない朝』系

| 語対 | 意味 |
|---|---|
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |
| `tu va` | 海 |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |

### 『窓に雨がある』通常読み

| 語対 | 意味 |
|---|---|
| `na ve` | 雨 |
| `ve lo` | 静かに休む |
| `lo ri` | 窓 |
| `ri ma` | 朝 |
| `ma se` | 開く |
| `se tu` | カーテン |
| `tu ko` | 鳥 |
| `ko na` | 戻って歌う |

### 『窓に雨がある』歩幅読み

| 語対 | 意味 |
|---|---|
| `na lo` | 死者が戻る |
| `lo ma` | 顔を持たない |
| `ma tu` | 名前が返事をする |
| `tu na` | 屋根が呼吸する |

## 一時語対

欠落読みでは、通常は隣り合わない二語が接触し、その作品内でだけ一時的な意味を持つことがある。

一時語対は本文とこの語彙集の両方に記録し、正規語対と混同しない。

## 読み方の例

`ka lin mo se ra`

隣接する組を順に読む。

- `ka lin` = 鳥
- `lin mo` = 眠る
- `mo se` = 月の下で
- `se ra` = 月

したがって「鳥は月の下で眠る。月……」まで読める。単語を一つずつ訳してはいけない。
