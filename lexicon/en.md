# エン語語彙集

エン語では、単独の語に固定された意味はない。意味を持つのは、左から右へ並んだ二語の組だけである。

`ka lin` と `lin ka` は別の語彙として扱う。

## 関係接辞

接辞は語の意味ではなく、隣接語対の読み方を制御する。接辞付き語対も必ず個別登録する。

| 接辞 | 操作 | 効果 |
|---|---|---|
| `in-` | 反転 | 次の関係を否定・反転する |
| `re-` | 回帰 | 直前の関係を呼び戻す |
| `con-` | 結合 | 左右の関係を集合として読む |
| `ex-` | 分離 | 次の関係を外へ放つ、切り離す |
| `sub-` | 潜在 | 表面関係の下に別関係を置く |

接辞だけから派生語対の意味を自動確定してはならない。現在、正式登録済みの接辞付き語対はない。

## 語長

短語・中語・長語を混在させる。長い語も単独では固定語義を持たない。

- 短語：2〜3文字
- 中語：4〜6文字
- 長語：7〜10文字

## 正規語対

### 『帰光』系

| 語対 | 意味 |
|---|---|
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |

### 『始点のない朝』系

| 語対 | 意味 |
|---|---|
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |

| `lo ri` | 窓 |

| 語対 | 意味 |
|---|---|

| `lo ma` | 顔を持たない |
| `ma tu` | 名前が返事をする |
| `tu na` | 屋根が呼吸する |

### `RP-0001 屋根だけが現在形`

| 語対 | 意味 |
|---|---|
| `tu ko` | 鳥（既存語対を再利用） |
| `ko ra` | 屋根 |
| `ra na` | 雨が始まる |
| `na ve` | 雨（既存語対を再利用） |
| `ve sa` | 声 |
| `sa li` | 残る |
| `li so` | 静けさになる |
| `so mi` | 屋根が覚えている |
| `mi re` | 去ったもの |
| `re tu` | 去ったものを鳥と呼ぶ |

### `RP-0011 川のあとから夜明けが戻る`

`nemi` は単独語義を持たない中語で、既存の `tu va`（海）の境界を二つへ分けるために導入された。

| 語対 | 意味 |
|---|---|
| `tu nemi` | 川、流れ下る水の道 |
| `nemi va` | 海へ入る |

### `RP-0017 あなたが止まった年齢をひらく`

`mero` と `ava` は単独語義を持たない。親子関係と年齢の交差を、三つの新しい境界として登録する。

| 語対 | 意味 |
|---|---|
| `su mero` | 自分を育てた者の生が止まった年齢、その年齢に初めて触れる日 |
| `mero ava` | その者が生きた年齢を越えて生きる、年上になる |
| `ava ni` | その年齢を越えた後にも、その者の子どもであり続ける |

`ava ni` の次には既存の `ni ke`（子ども）が続くため、年齢を越えた後にも輪は「子ども」へ戻る。

### `RP-0020 抱けなくなっても、手は昔の重さを捨てない`

`moravel` と `sela` は単独語義を持たない。成長した子の現在の身体と、親の手に残る「最後に抱けた重さ」のずれを三つの境界として登録する。

| 語対 | 意味 |
|---|---|
| `ku moravel` | かつて抱いた者が大きくなり、もう抱き上げられなくなった後にも、手が保持している最後に抱けた重さ |
| `moravel sela` | 手が覚えている小さな重さと、目の前の成長した身体が、同じ一人だと同時に分かること |
| `sela no` | 昔の大きさが、現在のその人を内側で呼ぶための私的な呼称へ変わること |

`no ta`（名）の次に `ta ku`（手の中にある）が続くため、昔の大きさから生まれた呼び方は再び手へ戻る。

### `RP-0021 飢えが終わっても、最初の一口は自分のものにならない`

`pali` は単独語義を持たない。分配の順番が身体習慣になる箇所だけを二つの境界として登録する。

| 語対 | 意味 |
|---|---|
| `ta pali` | 食べ物や乏しいものを分けるとき、自分の取り分より先に隣人の取り分へ手を向ける |
| `pali ku` | 飢えや乏しさが終わった後にも、その「他者から数え始める順序」が手の中に残っている |

`pali ku` の次には既存の `ku ve`（声）が続き、分配順序は家に伝わる声へ移る。

## 一時語対

欠落読みでは、通常は隣り合わない二語が接触し、その作品内でだけ一時的な意味を持つことがある。

一時語対は本文とこの語彙集の両方に記録し、正規語対と混同しない。

| 語対 | 意味 | 初出 |
|---|---|---|
| `tu ra` | 飛び立つ。`tu ko ra` から `ko` を欠落させた場合のみ成立 | `RP-0001` |

## 読み方の例

`ka lin mo se ra`

隣接する組を順に読む。

- `ka lin` = 鳥
- `lin mo` = 眠る
- `mo se` = 月の下で
- `se ra` = 月

したがって「鳥は月の下で眠る。月……」まで読める。単語を一つずつ訳してはいけない。
