# 02　始点のない朝

原詩言語：エン語

この詩の保存対象は出来事の順序ではなく、輪のどこを始まりと見なすかによって生じる因果の揺れである。

---

## A. エン語原詩

```text
ka lin mo se ra tu va ni ke su me yo ka
```

末尾の `ka` は先頭の `ka` と同一であり、詩は輪を作る。

### 語対

| 語対 | 意味 |
|---|---|
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |
| `tu va` | 海 |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |

### `ka` から読む

鳥は月の下で眠る。  
月は海へ沈む。  
海は子どもを覚えている。  
子どもは扉を開く。  
夜明けは鳥のもとへ戻る。

### `ni` から読む

子どもが扉を開く。  
夜明けが戻り、鳥は眠る。  
月が海へ沈み、  
海は、扉を開いた子どもを覚えている。

どちらも同じ語対を一度ずつ通る。異なるのは、読者が最初の原因として選んだ場所だけである。

---

## B. アレム語訳 — 「何度目の循環か」

この改訂では、鳥=`t-r`、月=`m-n`、海=`s-r`、子ども=`k-l`、夜明け=`y-r` を正規語根として固定した。

### 現在相

```text
Tar vi man.
Man na sar.
Kal na dar.
Yar ve tar.
```

鳥は現在の月の内側にいる。  
月が現在の海に触れている。  
子どもが現在の扉に触れている。  
夜明けが鳥へ近づいている。

### 内在相

```text
Tir vi min.
Min vi sir.
Kil vi dir.
Yir vi tir.
```

記憶の鳥が、記憶の月の内側にいる。  
記憶の月が、記憶の海の内側にある。  
記憶の子どもが、記憶の扉の内側にいる。  
記憶の夜明けが、記憶の鳥の内側にある。

### 欠如相

```text
Tur do mun.
Mun do sur.
Kul do dur.
Yur do tur.
```

届かない鳥が、失われた月の後ろに残る。  
失われた月が、失われた海の後ろに残る。  
失われた子どもが、開かない扉の後ろに残る。  
来なかった夜明けが、届かない鳥の後ろに残る。

### 接近相

```text
Ter ve men.
Men ve ser.
Kel ve der.
Yer ve ter.
```

近づく鳥が、近づく月へ向かう。  
近づく月が、近づく海へ向かう。  
近づく子どもが、近づく扉へ向かう。  
近づく夜明けが、近づく鳥へ向かう。

エン語原詩では始点が不明だった。アレム語訳では循環の始点を保存できないため、代わりに「これは現在の循環か、記憶された循環か、失われた循環か、再開しようとする循環か」を不明にした。

## C. ヴェラ語訳 — 「昨日を開く」

### 表記

```text
kali mora seyo
ratu vame nika
kesu meyo kali
mora seyo ratu
kali mora seyo
```

### 黙読

子どもは月を見る。  
海は、記憶の中の子どもを覚えている。  
開いた扉の先に、夜明けと子どもがいる。  
月は海へ視線を向ける。  
子どもは月を見る。

### 表層語彙

| 語 | 意味 |
|---|---|
| `kali` | 子ども |
| `mora` | 月 |
| `seyo` | 見る、視線を向ける |
| `ratu` | 海 |
| `vame` | 覚えている |
| `nika` | 記憶の中の子ども |
| `kesu` | 開いた扉 |
| `meyo` | 夜明け |

### 発声

```text
kalimoraseyo  → kalimo / raseyo
ratuvamenika  → ratuva / menika
kesumeyokali  → kesume / yokali
moraseyoratu  → morase / yoratu
kalimoraseyo  → kalimo / raseyo
```

### 発声された詩

昨日が始まる。  
扉の後で。

海は覚えている。  
まだ起きていないことを。

夜明けが戻る。  
子どもがそれを開いたから。

月が沈む。  
朝が来た後に。

昨日が始まる。  
扉の後で。

### 発声語彙

| 語 | 意味 |
|---|---|
| `kalimo` | 昨日が始まる |
| `raseyo` | 扉の後で |
| `ratuva` | 海が覚えている |
| `menika` | まだ起きていないこと |
| `kesume` | 夜明けが戻る |
| `yokali` | 子どもがそれを開いたために |
| `morase` | 月が沈む |
| `yoratu` | 朝が来た後に |

エン語の始点変更を完全には移せないため、ヴェラ語訳は表層と発声で原因と結果の順序を反転させた。

## 使用語彙と辞書

- エン語：原詩の12語対を一周して使用
- アレム語語根：`t-r`、`m-n`、`s-r`、`k-l`、`d-r`、`y-r`
- アレム語関係語：`vi`、`na`、`do`、`ve`
- ヴェラ語：表層語8語、発声語8語を使用
