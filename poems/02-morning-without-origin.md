# 02　始点のない朝

原詩言語：エン語

この詩の保存対象は出来事の順序ではなく、輪のどこを始まりと見なすかによって生じる因果の揺れである。

---

## A. エン語原詩

```text
ka lin mo se ra tu va ni ke su me yo ka
```

末尾の `ka` は先頭の `ka` と同一であり、詩は輪を作る。

### 語対

| 語対 | 意味 |
|---|---|
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |
| `tu va` | 海 |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |

### `ka` から読む

鳥は月の下で眠る。  
月は海へ沈む。  
海は子どもを覚えている。  
子どもは扉を開く。  
夜明けは鳥のもとへ戻る。

### `ni` から読む

子どもが扉を開く。  
夜明けが戻り、鳥は眠る。  
月が海へ沈み、  
海は、扉を開いた子どもを覚えている。

どちらも同じ語対を一度ずつ通る。異なるのは、読者が最初の原因として選んだ場所だけである。

## B. アレム語訳 — 「何度目の循環か」

### 現在相

```text
Par vi man.
Man na sar.
Kal na dar.
Mar ve par.
```

鳥は月の内側で眠る。  
月が海に触れる。  
子どもが扉に触れる。  
夜明けが鳥へ近づく。

### 内在相

```text
Pir vi min.
Min vi sir.
Kil vi dir.
Mir vi pir.
```

記憶の鳥は、記憶の月の内側にいる。  
月は海の記憶に沈んでいる。  
子どもは扉の記憶にいる。  
夜明けは鳥の記憶の中にある。

### 欠如相

```text
Pur do mun.
Mun do sur.
Kul do dur.
Mur do pur.
```

届かない鳥が、存在しない月の後ろに残る。  
月は、失われた海の後ろに残る。  
呼べない子どもが、開かない扉の後ろに残る。  
来なかった夜明けが、鳥の後ろに残る。

### 接近相

```text
Per ve men.
Men ve ser.
Kel ve der.
Mer ve per.
```

鳥が月へ戻ろうとしている。  
月が海へ近づいている。  
子どもが扉へ近づいている。  
夜明けが鳥へ戻ろうとしている。

エン語原詩では始点が不明だった。アレム語訳では循環の始点を保存できないため、代わりに「これは現在の循環か、記憶された循環か、失われた循環か、再開しようとする循環か」を不明にした。

## C. ヴェラ語訳 — 「昨日を開く」

### 表記

```text
kali mora seyo
ratu vame nika
kesu meyo kali
mora seyo ratu
kali mora seyo
```

### 黙読

子どもは月を見ている。  
海は子どもを覚えている。  
扉が夜明けへ開く。  
月は海へ沈む。  
子どもは月を見ている。

### 発声

```text
kalimoraseyo  → kalimo / raseyo
ratuvamenika  → ratuva / menika
kesumeyokali  → kesume / yokali
moraseyoratu  → morase / yoratu
kalimoraseyo  → kalimo / raseyo
```

### 発声された詩

昨日が始まる。  
扉の後で。

海は覚えている。  
まだ起きていないことを。

夜明けが戻る。  
子どもがそれを開いたから。

月が沈む。  
朝が来た後に。

昨日が始まる。  
扉の後で。

### 発声語彙

| 語 | 意味 |
|---|---|
| `kalimo` | 昨日が始まる |
| `raseyo` | 扉の後で |
| `ratuva` | 海が覚えている |
| `menika` | まだ起きていないこと |
| `kesume` | 夜明けが戻る |
| `yokali` | 子どもがそれを開いたために |
| `morase` | 月が沈む |
| `yoratu` | 朝が来た後に |

エン語の始点変更を完全には移せないため、ヴェラ語訳は表層と発声で原因と結果の順序を反転させた。
