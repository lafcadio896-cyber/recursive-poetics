# 03　窓に雨がある

原詩言語：ヴェラ語

この詩の保存対象は、穏やかな風景の内側に、発声によってのみ現れる別の出来事が重なっていることである。

---

## A. ヴェラ語原詩

### 表記

```text
nave lori mase
mira seno talu
sali more navi
keno vari sume
tora mise nalu
nave lori mase
```

### 黙読

雨が窓で静かに休んでいる。  
明かりが廊下で燃えている。  
子どもが扉に絵を描いている。  
朝がカーテンを開いている。  
鳥が屋根の上で歌っている。  
雨が窓で静かに休んでいる。

### 表層語彙

| 語 | 意味 |
|---|---|
| `nave` | 雨 |
| `lori` | 静かに休む |
| `mase` | 窓 |
| `mira` | 明かり |
| `seno` | 燃える |
| `talu` | 廊下 |
| `sali` | 子ども |
| `more` | 描く |
| `navi` | 扉 |
| `keno` | 朝 |
| `vari` | 開く |
| `sume` | カーテン |
| `tora` | 鳥 |
| `mise` | 歌う |
| `nalu` | 屋根 |

### 発声

```text
navelorimase  → navelo / rimase
mirasenotalu  → mirase / notalu
salimorenavi  → salimo / renavi
kenovarisume  → kenova / risume
toramisenalu  → torami / senalu
navelorimase  → navelo / rimase
```

### 発声された詩

死者たちが戻ってくる。  
顔を持たずに。

誰も気づかない。  
彼らはもう廊下に立っている。

家は覚えている。  
あなたの手を。

あなたの名は失われた。  
それでも、その名は返事をする。

上を見てはいけない。  
屋根が呼吸している。

死者たちが戻ってくる。  
顔を持たずに。

### 発声語彙

| 語 | 意味 |
|---|---|
| `navelo` | 死者たちが戻る |
| `rimase` | 顔を持たずに |
| `mirase` | 誰も気づかない |
| `notalu` | すでに中に立っている |
| `salimo` | 家が覚えている |
| `renavi` | あなたの手 |
| `kenova` | あなたの名は失われた |
| `risume` | それでも返事をする |
| `torami` | 上を見てはいけない |
| `senalu` | 屋根が呼吸している |

## B. アレム語訳 — 「風景が死者へ近づく」

この改訂では、水=`s-l` と子ども=`k-l` を分離し、名は一貫して `n-l`、死者は `d-t` を使う。

### 現在相

```text
Nav na mas.
Kal vi lam.
Tar na raf.
```

雨が現在の窓に触れている。  
現在の子どもが、現在の家の中にいる。  
現在の鳥が、現在の屋根にいる。

### 内在相

```text
Niv vi mis.
Kil vi lim.
Tir vi rif.
```

記憶の雨が、記憶の窓の内側にある。  
記憶の子どもが、記憶の家の中にいる。  
記憶の鳥が、記憶の屋根の内側にいる。

### 離行相

```text
Nov ra mos.
Kol ra lom.
Tor do rof.
```

遠ざかる雨が、遠ざかる窓から離れていく。  
遠ざかる子どもが、遠ざかる家から離れていく。  
遠ざかる鳥が、遠ざかる屋根の後ろに残る。

### 欠如相

```text
Nuv vi mus.
Kul do lum.
Tur do ruf.
```

降らなかった雨が、存在しない窓の内側にある。  
失われた子どもが、帰れない家の後ろに残る。  
届かない鳥が、失われた屋根の後ろに残る。

### 接近相

```text
Det ve lem.
Nel ve mes.
Her ve der.
```

近づく死者が、近づく家へ向かう。  
近づく名が、近づく窓へ向かう。  
近づく息が、近づく扉へ向かう。

### 現在相

```text
Nav na mas.
Kal vi lam.
Tar na raf.
```

雨が現在の窓に触れている。  
現在の子どもが、現在の家の中にいる。  
現在の鳥が、現在の屋根にいる。

同じ現在相へ戻っているが、接近相を読んだ後では、子どもが生者であるとは限らない。

## C. エン語訳 — 「歩幅の違う二つの詩」

```text
na ve lo ri ma se tu ko na
```

### 一語ずつ読む

| 語対 | 意味 |
|---|---|
| `na ve` | 雨 |
| `ve lo` | 静かに休む |
| `lo ri` | 窓 |
| `ri ma` | 朝 |
| `ma se` | 開く |
| `se tu` | カーテン |
| `tu ko` | 鳥 |
| `ko na` | 戻って歌う |

雨が静かに窓で休む。  
朝がカーテンを開く。  
鳥が戻って歌い、  
その歌は雨へ戻る。

### 一語飛ばしで読む

`na → lo → ma → tu → na` と進む。

| 語対 | 意味 |
|---|---|
| `na lo` | 死者が戻る |
| `lo ma` | 顔を持たない |
| `ma tu` | 名前が返事をする |
| `tu na` | 屋根が呼吸する |

死者が戻る。  
顔を持たずに。  
失われた名前が返事をし、  
屋根が呼吸する。

一語ずつ歩けば朝の詩になり、一語飛ばしで歩けば死者の詩になる。ヴェラ語の発声による切り替えを、エン語では輪を歩く速度の違いへ置き換えた。

## 使用語彙と辞書

- ヴェラ語：表層語15語、発声語10語を使用
- アレム語語根：`n-v`、`m-s`、`k-l`、`l-m`、`t-r`、`r-f`、`d-t`、`n-l`、`h-r`、`d-r`
- アレム語関係語：`na`、`vi`、`ra`、`do`、`ve`
- エン語：通常読み8語対、歩幅読み4語対を使用
