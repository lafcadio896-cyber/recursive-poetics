# 石が水の記憶を離れる

- 管理番号：`RP-0010`
- 生成日時：2026-08-11T03:04+09:00
- 原詩言語：アレム語
- 題材：雨のあとの水辺で、石が水の内在から離れ、子どもの手の現在へ移る

雨、水、海、石、子ども、手、夜明けだけを置く。新しい三子音語根 `k-r-s` を「石、岩片、手で触れられる大地の断片」として導入し、石の材質ではなく、水と手のあいだで変化する存在距離を詩の中心にする。

## 原詩 — アレム語

> Karas na sal.  
> Nav na karas.  
> Kiris vi sil.  
> Koros ra sar.  
> Kurus do sur.  
> Keres ve kal.  
> Karas na kat.  
> Yar na sal.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Karas na sal.` | 現在相の石｜接触している｜現在相の水 |
| `Nav na karas.` | 現在相の雨｜接触している｜現在相の石 |
| `Kiris vi sil.` | 内在相の石｜内部にある｜内在相の水 |
| `Koros ra sar.` | 離行相の石｜離れていく｜現在相の海 |
| `Kurus do sur.` | 欠如相の石｜後ろに残る｜欠如相の海 |
| `Keres ve kal.` | 接近相の石｜近づいていく｜現在相の子ども |
| `Karas na kat.` | 現在相の石｜接触している｜現在相の手 |
| `Yar na sal.` | 現在相の夜明け｜接触している｜現在相の水 |

### 自然な日本語訳

石は水に触れている。  
雨がその表面を打つ。

やがて石は、水そのものではなく、  
水の記憶の内側にあるものになる。

海から遠ざかった石は、  
一度、失われた海の後ろへ置き去りにされる。

それでも石は子どもへ近づき、  
ふたたび手に触れられる現在になる。

夜明けだけが、まだ水の上にある。

### その言語で起きていること

新語根 `k-r-s` は、石を不変の物質としてではなく、「水にある石」「記憶にある石」「海から離れる石」「届かない石」「手へ近づく石」という同一概念の距離変化として扱う。`karas / kiris / koros / kurus / keres` はすべて同じ子音骨格を保つ。

### 翻訳による変形

アレム語では石そのものが距離を移る。翻訳先では石を直接新語化せず、エン語では「手・喪失・帰還・水面・記憶」の輪へ、ヴェラ語では「月・海・記憶・夜明け」の二重分節へ変換する。

## 翻訳 — エン語

石を一対一対応させる新しい語対は作らない。手から始め、失われたものが光として戻り、水面に触れて記憶になる既存の『帰光』の輪を使う。

### 輪

> ta ku ve li ho du re ma ri se no ta

末尾の `ta` は先頭と同一であり、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |

### `ta` から読む

手の中にあるものは声になり、家に残る。息は扉の後ろで失われる。失われたものは戻り、光となって水面に触れ、記憶となり、最後に名として再び手へ閉じる。

### `ma` から読む

光が水面に触れ、それが記憶になる。名は手の中にあり、声は家に残る。息は扉の後ろで失われ、そこから再び光へ戻る。

### 自然な日本語訳

手に収まったものは、エン語では石ではなく名になる。失われたものが戻って水面へ触れたあと、その出来事自体が記憶となり、名が再び手へ閉じる。

### 翻訳による変形

アレム語の「石が海から手へ移る」という距離変化を、エン語では「手→喪失→帰還→水面→記憶→名」という輪へ変えた。新語対は導入していない。

## 翻訳 — ヴェラ語

表層では月・海・記憶・夜明け・子どもが静かに並ぶ。発声すると、海がまだ起きていないことを覚え、夜明けの帰還が子どもの行為と結びつく。

### 表層詩

> mora seyo ratu  
> ratu vame nika  
> kesu meyo kali

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `mora seyo ratu` | 月｜見る・視線を向ける｜海 |
| `ratu vame nika` | 海｜覚えている｜記憶の中の子ども |
| `kesu meyo kali` | 開いた扉｜夜明け｜子ども |

### 発声

> moraseyoratu → morase / yoratu  
> ratuvamenika → ratuva / menika  
> kesumeyokali → kesume / yokali

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `morase / yoratu` | 月が沈む｜朝が来た後に |
| `ratuva / menika` | 海が覚えている｜まだ起きていないこと |
| `kesume / yokali` | 夜明けが戻る｜子どもがそれを開いたために |

### 表層詩の自然な日本語訳

月は海へ視線を落とす。  
海は、記憶の中の子どもを覚えている。  
開いた境界に、夜明けと子どもが並ぶ。

### 発声された詩の自然な日本語訳

朝が来た後で、月が沈む。  
海は、まだ起きていないことを覚えている。  
夜明けが戻るのは、子どもがそれを開いたからだ。

### 翻訳による変形

アレム語では石の距離が変わるが、ヴェラ語では物体そのものを保存せず、「海が未来を記憶する」という時間のずれへ変える。表層と発声で音列は完全に同一で、境界だけが変わる。

## 検査

- アレム語：新語は `k-r-s` の1語根のみ。既存の正規語根 `m-r / s-l / n-l / k-t / v-l / l-m / h-r / d-r / n-v / m-s / t-r / r-f / m-n / s-r / k-l / y-r / d-t / g-r-n` および廃止語根 `p-r` と衝突しない。
- アレム語：`karas / kiris / koros / kurus / keres` は三子音語根 `C1VC2VC3` の形成規則に一致する。既存語 `sal / sil / nav / sar / sur / kal / kat / yar` と関係語 `na / vi / ra / do / ve` はすべて辞書登録済み。
- エン語：輪の11個の隣接語対はすべて『帰光』系の正規辞書登録済み。末尾 `no ta` まで含め未説明語対なし。
- ヴェラ語：`moraseyoratu = morase + yoratu`、`ratuvamenika = ratuva + menika`、`kesumeyokali = kesume + yokali`。表層音列と発声側の連続音列は文字単位で一致し、全行で境界が異なる。
- 同じ語形・語根・語対への無関係な意味追加、旧用法の再利用、未説明語の使用なし。
- 新文法を一度の用例から作っていない。
