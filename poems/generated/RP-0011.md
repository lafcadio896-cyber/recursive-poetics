# 川のあとから夜明けが戻る

- 管理番号：`RP-0011`
- 生成日時：2026-08-12T03:03+09:00
- 原詩言語：エン語
- 題材：月が沈むところから川が海へ入り、海の記憶、子ども、扉、夜明け、鳥を一周して再び月へ戻る

川が海へ入ることと、子どもが扉を開いて夜明けを迎えることを同じ輪へ置く。川を単独の語として作らず、既存の「沈む」`ra tu` と「海が覚えている」`va ni` の間へ中語 `nemi` を挿入し、二つの新しい境界だけで「川」と「海へ入る」を生じさせる。

## 原詩 — エン語

### 輪

> ka lin mo se ra tu nemi va ni ke su me yo ka

末尾の `ka` は先頭と同一であり、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |
| `tu nemi` | 川、流れ下る水の道 |
| `nemi va` | 海へ入る |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |

### `tu` から読む

川は海へ入る。海は覚えている。記憶の先に子どもがいて、子どもは扉を開く。扉の向こうから夜明けが戻り、鳥は月の下で眠る。月が沈むと、その沈みの先に再び川が現れる。

### `ni` から読む

子どもが扉を開く。夜明けが戻り、鳥が月の下で眠る。月が沈むところから川が生まれ、川は海へ入る。最後に海が覚えているものとして、子どもへ輪が閉じる。

### 自然な日本語訳

川は、月が沈んだあとから流れてくる。  
海へ入った水を、海は忘れない。

その記憶の中で子どもが扉を開くと、  
夜明けが戻り、鳥は月の下で眠る。

けれど輪を川から読み直せば、  
朝より先に海の記憶があり、  
子どもはその記憶の後から現れる。

### その言語で起きていること

新語 `nemi` 自体には固定語義を与えない。`tu nemi` の境界でだけ「川」が、`nemi va` の境界でだけ「海へ入る」が成立する。既存の `tu va` は「海」であり、`nemi` の挿入によって元の境界を壊し、同じ位置に「川→海へ入る」という二段階の関係を作った。

### 翻訳による変形

エン語では川そのものより、川が海へ変わる境界と、海の記憶から子どもへ戻る環が中心になる。アレム語ではこの変化を「接近する水→触れる水→海の内部にある水」という存在距離へ、ヴェラ語では「海がまだ起きていない出来事を覚えている」という二重分節へ変換する。

## 翻訳 — アレム語

川に相当する新語根は作らない。流れを、水が海へ接近し、接触し、その内部へ入る距離変化として訳す。

> Sel ve sar.  
> Sal na sar.  
> Sil vi sir.  
> Kal na dar.  
> Yer ve kal.  
> Yar na dar.  
> Tar vi man.  
> Mon ra yar.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Sel ve sar.` | 接近相の水｜近づいていく｜現在相の海 |
| `Sal na sar.` | 現在相の水｜接触している｜現在相の海 |
| `Sil vi sir.` | 内在相の水｜内部にある｜内在相の海 |
| `Kal na dar.` | 現在相の子ども｜接触している｜現在相の扉 |
| `Yer ve kal.` | 接近相の夜明け｜近づいていく｜現在相の子ども |
| `Yar na dar.` | 現在相の夜明け｜接触している｜現在相の扉 |
| `Tar vi man.` | 現在相の鳥｜内部にある｜現在相の月 |
| `Mon ra yar.` | 離行相の月｜離れていく｜現在相の夜明け |

### 自然な日本語訳

水が海へ近づき、触れ、やがて海の内側の水になる。  
子どもは扉に触れ、夜明けがその子へ近づく。  
朝が境界に触れるころ、鳥は月の内側にあり、  
月だけが夜明けから遠ざかっていく。

### 翻訳による変形

エン語の「川」という新しい境界語義を、アレム語では新語にせず `s-l` の母音相で展開した。川と海を別物として固定するのではなく、水が海へ接近し、接触し、内部化される過程として読む。

## 翻訳 — ヴェラ語

表層では月・海・記憶・子ども・開いた扉・夜明けが静かに並ぶ。発声すると、海の記憶が未来へ向き、子どもの行為が夜明けの帰還理由になる。

### 表層詩

> mora seyo ratu  
> ratu vame nika  
> kesu meyo kali

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `mora seyo ratu` | 月｜見る・視線を向ける｜海 |
| `ratu vame nika` | 海｜覚えている｜記憶の中の子ども |
| `kesu meyo kali` | 開いた扉｜夜明け｜子ども |

### 発声

> moraseyoratu → morase / yoratu  
> ratuvamenika → ratuva / menika  
> kesumeyokali → kesume / yokali

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `morase / yoratu` | 月が沈む｜朝が来た後に |
| `ratuva / menika` | 海が覚えている｜まだ起きていないこと |
| `kesume / yokali` | 夜明けが戻る｜子どもがそれを開いたために |

### 表層詩の自然な日本語訳

月は海を見る。  
海は、記憶の中の子どもを覚えている。  
開いた境界に、夜明けと子どもがいる。

### 発声された詩の自然な日本語訳

朝が来たあとで、月が沈む。  
海は、まだ起きていないことを覚えている。  
夜明けが戻るのは、子どもがそれを開いたからだ。

### 翻訳による変形

エン語では始点によって「海が先か、子どもの行為が先か」が揺れる。ヴェラ語ではその揺れを表層と発声へ分離し、表層では海が過去を覚えているように見せ、発声では未来を記憶していたことを明かす。

## 今回覚えられる語彙

### エン語

- `tu nemi` — 川、流れ下る水の道
- `nemi va` — 海へ入る

`nemi` 単独には固定語義を与えない。

### アレム語

- `s-l` — 水、水面
- `s-r` — 海
- `k-l` — 子ども
- `d-r` — 扉
- `y-r` — 夜明け
- `t-r` — 鳥
- `m-n` — 月

### ヴェラ語

表層：`mora / seyo / ratu / vame / nika / kesu / meyo / kali`。発声：`morase / yoratu / ratuva / menika / kesume / yokali`。

## 今回覚えられる文法

新文法なし。エン語の環状始点読み、アレム語の母音相、ヴェラ語の再分節を反復する。

## 今回使用した既存語彙

### エン語

`ka lin / lin mo / mo se / se ra / ra tu / va ni / ni ke / ke su / su me / me yo / yo ka`。

### アレム語

語根 `s-l / s-r / k-l / d-r / y-r / t-r / m-n`、母音相 `a / i / o / e`、関係語 `na / vi / ra / ve`。

### ヴェラ語

表層 `mora / seyo / ratu / vame / nika / kesu / meyo / kali`、発声 `morase / yoratu / ratuva / menika / kesume / yokali`。

## 新しく生じた語彙・規則

### エン語

- `tu nemi` — 川、流れ下る水の道。
- `nemi va` — 海へ入る。

新しい文法規則は追加しない。`nemi` は既存の `tu va` を分割するために導入された中語だが、単独語義は持たない。

## 検査

- エン語：輪の13境界のうち新規は `tu nemi` と `nemi va` の2件のみ。その他11件は正規辞書登録済み。
- エン語：`nemi` は4文字の中語で、単独には固定意味を付与していない。`tu va`＝海の既存語義は変更していない。
- エン語：末尾 `yo ka` と先頭 `ka lin` を含めて輪は閉じ、未説明の隣接語対はない。
- アレム語：`sel/s-l/e`、`sal/s-l/a`、`sil/s-l/i`、`sar/s-r/a`、`sir/s-r/i`、`kal/k-l/a`、`dar/d-r/a`、`yer/y-r/e`、`yar/y-r/a`、`tar/t-r/a`、`man/m-n/a`、`mon/m-n/o` に分解できる。関係語 `ve/na/vi/ra` は登録済み。廃止語根なし。
- ヴェラ語：`moraseyoratu = morase + yoratu`、`ratuvamenika = ratuva + menika`、`kesumeyokali = kesume + yokali`。表層音列と発声側音列は文字単位で一致し、全行で境界が異なる。
- 同じ語形・語根・語対への無関係な意味追加、旧用法の再利用、未説明語の使用なし。
- 新文法を一度の用例から作っていない。

## 未解決事項

川が海へ入ったことで海が記憶を持つのか、海が先に記憶していたから川がそこへ到達したのかは、始点によって決まらない。
