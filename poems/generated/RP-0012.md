# 鳥のいない屋根に昨日が始まる

- 管理番号：`RP-0012`
- 生成日時：2026-08-13T09:17+09:00
- 原詩言語：ヴェラ語
- 題材：鳥、雨、光、子ども、月が同じ夕べに見える表層と、発声すると鳥の不在と時間のずれが現れる二重の風景

表層では、鳥が屋根で休み、雨が窓辺で歌い、光が屋根を描き、子どもが月を見る。発声すると、屋根は去った鳥を覚え、雨は失われた歌を繰り返し、光は羽のない空所を描き、昨日は扉の後から始まる。

## 原詩 — ヴェラ語

### 表層詩

> tora lori nalu  
> nave mise mase  
> mira more nalu  
> kali mora seyo

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `tora lori nalu` | 鳥｜静かに休む｜屋根 |
| `nave mise mase` | 雨｜歌う｜窓 |
| `mira more nalu` | 明かり｜描く｜屋根 |
| `kali mora seyo` | 子ども｜月｜見る |

### 発声

> toralorinalu → toralo / rinalu  
> navemisemase → navemi / semase  
> miramorenalu → miramo / renalu  
> kalimoraseyo → kalimo / raseyo

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `toralo / rinalu` | 屋根が覚えている｜去った後の鳥 |
| `navemi / semase` | 雨が繰り返す｜失われた歌 |
| `miramo / renalu` | 昼の光が描く｜羽のない空所 |
| `kalimo / raseyo` | 昨日が始まる｜扉の後で |

### 自然な日本語訳

鳥は屋根で眠り、  
雨は窓辺で歌っている。  
光は屋根の輪郭を描き、  
子どもは月を見る。

けれど声にすると、  
屋根が覚えているのは去った鳥で、  
雨が繰り返すのは失われた歌で、  
光が描くのは羽のない空所になる。  
そして昨日は、扉の後から始まる。

### その言語で起きていること

四行とも、表層音列と発声側音列は文字単位で完全に一致する。表層では現在の風景が並ぶが、発声では同じ音が「すでに去ったもの」「失われたもの」「空所」「昨日」へ分かれ直す。新語は使わず、既存の再分節だけを組み替えて一篇を成立させた。

### 翻訳による変形

ヴェラ語では、同じ音列の境界を変えるだけで現在と不在が重なる。アレム語ではこの重なりを母音相の変化へ、エン語では輪の始点による因果の反転へ移す。

## 翻訳 — アレム語

> Tar na raf.  
> Nav na raf.  
> Mar na raf.  
> Kal vi man.  
> Tur do ruf.  
> Niv vi rif.  
> Mir vi rif.  
> Mon ra kal.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Tar na raf.` | 現在相の鳥｜接触している｜現在相の屋根 |
| `Nav na raf.` | 現在相の雨｜接触している｜現在相の屋根 |
| `Mar na raf.` | 現在相の光｜接触している｜現在相の屋根 |
| `Kal vi man.` | 現在相の子ども｜内部にある｜現在相の月 |
| `Tur do ruf.` | 欠如相の鳥｜後ろに残る｜欠如相の屋根 |
| `Niv vi rif.` | 内在相の雨｜内部にある｜内在相の屋根 |
| `Mir vi rif.` | 内在相の光｜内部にある｜内在相の屋根 |
| `Mon ra kal.` | 離行相の月｜離れていく｜現在相の子ども |

### 自然な日本語訳

鳥と雨と光は、いま屋根に触れている。  
子どもの内側には、まだ月がある。

鳥が欠如へ移ると、屋根も欠如の側へ沈み、  
雨と光だけが屋根の記憶へ残る。  
月は子どもから遠ざかるが、子ども自身は現在に残る。

### 翻訳による変形

ヴェラ語の「同じ音列に現在と不在が同居する」構造を、アレム語では同じ語根が現在相・内在相・欠如相・離行相へ移る構造として展開した。

## 翻訳 — エン語

### 輪

> ka lin mo se ra tu va ni ke su me yo ka

末尾の `ka` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 意味 |
|---|---|
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |
| `tu va` | 海 |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |

### `ka` から読む

鳥は月の下で眠る。月は沈み、海へ至る。海は覚えている。記憶の先で子どもが扉を開くと、夜明けが戻り、輪は鳥へ戻る。

### `ni` から読む

子どもが扉を開く。夜明けが戻り、鳥が月の下で眠る。月が沈んで海へ至ったあと、海の記憶が再び子どもを輪の始点へ戻す。

### 自然な日本語訳

鳥が眠る夜と、子どもが扉を開く朝は、同じ輪の上にある。  
海が先に覚えていたのか、子どもが先に朝を開いたのかは、どこから読み始めるかで変わる。

### 翻訳による変形

ヴェラ語では境界の切り替えで不在が現れた。エン語では同じ語対集合の始点を変えることで、鳥の夜と子どもの朝の因果が入れ替わる。
