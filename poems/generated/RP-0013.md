# 月が去ったあとにも朝はある

- 管理番号：`RP-0013`
- 生成日時：2026-08-14T03:03+09:00
- 原詩言語：アレム語
- 題材：月と雨が離れたあとに夜明けと光が残り、子どもの手の内にある名へ現在が戻ってくる

月と雨そのものを取り戻すのではなく、それらが去ったあとに何が残るかを描く。アレム語の関係語 `do` を、物理的な「後ろに残る」だけでなく「出来事の後に結果が残る」という方向へ一度だけ拡張して使う。ただし今回の一例だけでは文法化せず、言語史上の革新的用法として記録する。

## 原詩 — アレム語

> Mun ra yar.  
> Yar do mun.  
> Nav ra mar.  
> Mar do nav.  
> Kal na dar.  
> Nal vi kat.  
> Mer ve kal.  
> Mar na kat.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Mun ra yar.` | 欠如相の月｜離れていく｜現在相の夜明け |
| `Yar do mun.` | 現在相の夜明け｜後ろに残る｜欠如相の月 |
| `Nav ra mar.` | 現在相の雨｜離れていく｜現在相の光 |
| `Mar do nav.` | 現在相の光｜後ろに残る｜現在相の雨 |
| `Kal na dar.` | 現在相の子ども｜接触している｜現在相の扉 |
| `Nal vi kat.` | 現在相の名｜内部にある｜現在相の手 |
| `Mer ve kal.` | 接近相の光｜近づいていく｜現在相の子ども |
| `Mar na kat.` | 現在相の光｜接触している｜現在相の手 |

### 自然な日本語訳

月が失われても、朝はそのあとに残る。  
雨が離れていけば、そのあとには光が残る。

子どもは扉に触れ、  
名を手の内に持っている。  
遠くから近づいてきた光は、  
最後にその手へ触れる。

### その言語で起きていること

`do` は正規辞書では「後ろに残る」という空間・配置の関係語である。ここでは `Yar do mun` と `Mar do nav` を、月や雨という先行状態の後に夜明けや光が結果として残るようにも読ませる。まだ語義変更ではなく、文脈依存の革新的用法である。

### 翻訳による変形

アレム語では、喪失したものと現在に残ったものの距離が中心になる。エン語では「失われる→戻る」が輪の内部で循環する因果へ、ヴェラ語では穏やかな表層の下に「消された名」「忘れられた声」を持つ二重詩へ変換する。

## 翻訳 — エン語

### 輪

> ma ri se no ta ku ve li ho du re ma

末尾の `ma` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |

### `ma` から読む

光が水面に触れ、その接触は記憶になる。記憶は名となって手の中にあり、声は家に残る。息は扉の後ろにあり、やがて失われ、失われたところから光が戻ってくる。

### `du` から読む

失われることから始めると、まず何かが戻ってくる。その戻りを光と呼び、光が水へ触れたことが記憶となり、名、手、声、家、息、扉を経て再び喪失へ閉じる。

### 自然な日本語訳

失われたものの次には、戻ってくるものがある。  
戻った光が水に触れ、そのことが記憶になる。

記憶は名として手の中に残り、  
声は家に、息は扉の向こうに残る。  
輪をどこから読むかによって、喪失は終点にも始点にもなる。

### 翻訳による変形

アレム語の `do` が作る「出来事の後に残るもの」を、エン語では `du re / re ma` の隣接関係による「失われる／戻る」の連続へ変えた。エン語では結果そのものより、喪失と帰還が同じ輪の隣り合う境界であることが中心になる。

## 翻訳 — ヴェラ語

### 表層詩

> mare lino saku  
> nami sera toku  
> vela nori mado  
> hara dume rino

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `mare lino saku` | 光｜水・水面｜触れる |
| `nami sera toku` | 名｜手｜眠る・静止している |
| `vela nori mado` | 声｜家｜残る |
| `hara dume rino` | 息｜扉の向こう｜戻る |

### 発声

> marelinosaku → mareli / nosaku  
> namiseratoku → namise / ratoku  
> velanorimado → velano / rimado  
> haradumerino → haradu / merino

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `mareli / nosaku` | 誰かが呼ぶ｜消された名前 |
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |
| `velano / rimado` | 家が開いている｜死者の後ろで |
| `haradu / merino` | 息が近づく｜どの身体からでもなく |

### 表層詩の自然な日本語訳

光が水に触れる。  
名は手の中で眠る。  
声は家に残り、  
息は扉の向こうから戻ってくる。

### 発声された詩の自然な日本語訳

誰かが、消された名を呼んでいる。  
手だけが、声の忘れたものを覚えている。  
家は死者の後ろで開き、  
どの身体にも属さない息が近づいてくる。

### 翻訳による変形

アレム語では「去った後にも結果が残る」ことが明示される。ヴェラ語では、何が去ったのかを表層から消し、発声側だけに消された名や忘れられた声を残すことで、結果から原因を逆照射する。
