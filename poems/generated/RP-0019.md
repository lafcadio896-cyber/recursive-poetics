# 名の届かない未来へ、仕事だけが残る

- 管理番号：`RP-0019`
- 生成日時：2026-08-20T03:00+09:00
- 原詩言語：アレム語
- 題材：死者の名が次の世代へ届かなくても、その人の仕事・手入れ・技だけは別の手へ受け継がれて効き続ける

まず日本語で「人は、自分の名が届かない未来にも、仕事だけを届かせることがある」という核を置いた。最近の親の年齢や伴侶喪失とは異なり、個人の記憶ではなく、名前を失った後にも他者を支える労働の残効を扱う。

## 原詩 — アレム語

> Farat do dat.  
> Nul ra kal.  
> Girin vi farat.  
> Garan na kal.  
> Firit vi kat.  
> Farat na kat.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Farat do dat.` | 現在相の「名より長く働く仕事」｜出来事の後に結果として残る｜現在相の死者 |
| `Nul ra kal.` | 欠如相の名｜離れていく｜現在相の子ども |
| `Girin vi farat.` | 内在相の種｜内部にある｜現在相の「名より長く働く仕事」 |
| `Garan na kal.` | 現在相の種｜触れている｜現在相の子ども |
| `Firit vi kat.` | 内在相の「名より長く働く仕事」｜内部にある｜現在相の手 |
| `Farat na kat.` | 現在相の「名より長く働く仕事」｜触れている｜現在相の手 |

### 自然な日本語訳

死者のあとに、仕事が残る。  
名は、子どもへ届かない。

それでも仕事の内側にあった種は、  
いま、その子どもに触れる。

名を知らない手の内側へ、  
仕事だけが入っていく。

そして最後には、  
名前ではなく、  
今日の手に触れている仕事がある。

人は、  
自分の名が届かない未来にも、  
仕事だけを届かせることがある。

### その言語で起きていること

新語根 `f-r-t` は、単なる職業や作業ではない。行為者の名や生が届かなくなった後にも、別の人の手を通して効き続ける仕事・手入れ・技の残効を一つの概念として持つ。

`farat → firit → farat` と、仕事は現在相から別の手の内在相へ入り、最後に再び現在相として手へ触れる。一方、名 `n-l` は `nul`（欠如相）のまま子どもから離れていく。名前は継承されず、仕事だけが距離を越える。

`Farat do dat` は既存の慣用 `X do Y` を再使用する。ここでは「死者という出来事・状態の後、その結果として仕事が残る」と読む。新しい文法化は行わない。

### 翻訳による変形

エン語では「仕事」という概念を直接移植せず、手に入ったものが声・家・息・喪失・光・記憶・名を巡り、再び手へ戻る輪に変換する。ヴェラ語では、表層では名が手の中で眠る静かな像を置き、発声すると「声が忘れたものを手だけが覚えている」へ反転させる。

## 翻訳 — エン語

### 輪

> ta ku ve li ho du re ma ri se no ta

末尾の `ta` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |

### `ta` から読む

手の中に入ったものは声になり、家に残り、息になって扉の後ろへ移る。やがて失われても、光として戻り、水面へ触れ、記憶になり、最後には名になる。その名は再び手へ戻る。

### `du` から読む

最初に喪失がある。失われたものは、誰が始めたかを説明する前に光として戻り、記憶と名を経て手へ入る。こちらから読むと、継承とは「名を覚えてから手にすること」ではなく、「先に手に入り、後から名になること」に見える。

### 自然な日本語訳

誰のものだったかを知らないまま、  
手は先に受け取っている。

声になり、家に残り、  
いちど失われても、  
別の形で戻ってくる。

記憶が名になるのは、  
いつも手に入った後だ。

### その言語で起きていること

新語対は作らず、既存の「帰光」系の輪を `ta` から始める。原詩で明示された「仕事」は消え、代わりに、何かが先に手へ入り、喪失と回帰を経てから名になる順序そのものを継承として読む。

### 翻訳による変形

アレム語では名が届かず仕事だけが残る。エン語では、手に入ったものが後から名へ変わるため、継承の順番そのものが反転する。

## 翻訳 — ヴェラ語

### 表層詩

> nami sera toku  
> mira more nalu

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `nami sera toku` | 名｜手｜眠る・静止している |
| `mira more nalu` | 明かり｜描く｜屋根 |

### 表層詩の自然な日本語訳

名は、手の中で眠っている。  
明かりが、誰かの残した形をなぞるように屋根を描く。

### 発声

> namiseratoku → namise / ratoku  
> miramorenalu → miramo / renalu

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |
| `miramo / renalu` | 昼の光が描く｜羽のない空所 |

### 発声された詩の自然な日本語訳

声が忘れたものを、  
手だけが覚えている。

昼の光は、  
もう誰のものでもない空所の形だけを描く。

### その言語で起きていること

表層では「名が手の中にある」ように見える。しかし発声すると、名そのものは消え、残るのは「手だけが覚えている」という身体側の記憶である。第二行では、作った者そのものではなく、その者がいなくなった後の輪郭だけが光に描かれる。

### 翻訳による変形

アレム語の `f-r-t` が一語で持っていた「名より長く働く仕事」を、ヴェラ語では「声が忘れても手が覚える」という二重分節へほどいた。仕事の内容ではなく、忘却の速度が声と手で違うことを保存する。

## 今回覚えられる語彙

### アレム語 — 新語根

- `f-r-t` — 行為者の名や生が届かなくなった後にも、別の人の手を通して効き続ける仕事・手入れ・技の残効
- `farat` — いま現在、別の人の手で効いているその仕事
- `firit` — 別の身体・手の内側へ取り込まれ、技や手順として内在しているその仕事

五相は `farat / firit / forot / furut / feret`。今回本文では `farat` と `firit` を使用した。

### エン語

`ta ku / ku ve / ve li / li ho / ho du / du re / re ma / ma ri / ri se / se no / no ta`。すべて既存の正規語対。

### ヴェラ語

表層：`nami / sera / toku / mira / more / nalu`。発声：`namise / ratoku / miramo / renalu`。すべて既存語彙。

## 今回覚えられる文法

新文法なし。アレム語の母音相と慣用 `X do Y`、エン語の環状始点読み、ヴェラ語の再分節を使用する。

## 詩的強度の自己検査

- 日本語自然訳だけで「名が失われても仕事が未来の手へ届く」という一篇として成立する。
- 中心行「人は、自分の名が届かない未来にも、仕事だけを届かせることがある」を持つ。
- 最近多用した雨・月・鳥・朝を中心像にしていない。
- 直近の親の死亡年齢、伴侶喪失、二人暮らしの身体習慣とも中心関係が重複しない。
- 新語 `f-r-t` は単なる物体名・職業名ではなく、忘却後にも他者へ効き続ける労働という概念を切り取る。
- アレム語の母音相が「現在の仕事→手の内側の仕事→現在の仕事」という継承の移動に寄与している。
- 三言語は、仕事の存在距離／手から名へ巡る輪／声と手の忘却速度という別々の構造へ変形している。
