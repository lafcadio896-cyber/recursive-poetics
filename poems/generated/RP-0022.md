# 子どものまま、手の向きだけが変わる

- 管理番号：`RP-0022`
- 生成日時：2026-08-23T03:01+09:00
- 原詩言語：アレム語
- 題材：育てられた者が初めて育てた者を支える日、親子という関係は終わらず、支える手の向きだけが反転する

まず日本語で「親を支えた日、子どもを卒業したのではない。子どものまま、手の向きだけが変わった」という核を置いた。直近の継承、身体に残る重さ、飢えの分配順序とは離れ、同じ二人の関係が保たれたまま、支える方向だけが変わる瞬間を扱う。

## 原詩 — アレム語

> Kal na kat.  
> Pelem ve kal.  
> Palam na kat.  
> Pilim vi kit.  
> Kal na palam.  
> Kat na kal.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Kal na kat.` | 現在相の子ども｜接触している｜現在相の手 |
| `Pelem ve kal.` | 接近相の「支えの向きが親から子へ反転する瞬間」｜近づいていく｜現在相の子ども |
| `Palam na kat.` | 現在相の「支えの向きの反転」｜接触している｜現在相の手 |
| `Pilim vi kit.` | 内在相の「支えの向きの反転」｜内部にある｜内在相の手 |
| `Kal na palam.` | 現在相の子ども｜接触している｜現在相の「支えの向きの反転」 |
| `Kat na kal.` | 現在相の手｜接触している｜現在相の子ども |

### 自然な日本語訳

最初は、  
あなたを支える手に、  
子どもの手が触れていた。

やがて、  
向きが変わる日が近づく。

親を支えた日、  
子どもを卒業したのではない。

子どものまま、  
手の向きだけが変わった。

その向きは、  
一度変わると手の内側に残る。

それでも最後に触れているのは、  
手と、  
子どもだ。

### その言語で起きていること

新語根 `p-l-m` は介護一般や「親」を指す語ではない。育てられた者が、初めて自分を育てた者を支える側へ回るときに生じる、親子間の支援方向の反転そのものを表す。

`pelem → palam → pilim` と、反転は「近づく出来事」から「いま起きている出来事」へ移り、最後には手の内側に取り込まれる。一方、子ども `k-l` は最初から最後まで `kal` の現在相に留まる。役割の方向は変わるが、子どもであることの距離は変わらない。

### 翻訳による変形

エン語では親子を直接言わず、「名」と「手」が一つの輪でつながることで、役割名より先に身体が動く構造へ変える。ヴェラ語では表層に「名・手・眠る」を置き、発声すると「声が忘れたものを手だけが覚えている」となり、呼称より身体の方が役割変化を先に知る形へ圧縮する。

## 翻訳 — エン語

### 輪

> ta ku ve li ho du re ma ri se no ta

末尾の `ta` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |

### `ta` から読む

最初に手の中にあるものが、声になり、家に残り、息として境界の向こうへ移る。いったん失われても戻り、光になり、触れたものが記憶になり、最後に名になる。その名は再び手の中へ戻る。

### `no` から読む

最初に名があり、その名が手の中へ入る。手は声と家と息を通り、喪失と回帰を経て、最後にまた記憶から名へ戻る。この始点では、名が役割を決めるのではなく、何度も手へ戻ることで名の意味が更新されるように見える。

### 自然な日本語訳

役割の名より先に、  
手が動くことがある。

支えたあとで、  
ようやく自分が  
支える側へ回ったのだと分かる。

名は変わらない。  
変わったのは、  
手がどちらへ向くかだけだ。

### その言語で起きていること

新語対は作らず、既存の「帰光」系の環を使う。`no ta`（名）から `ta ku`（手の中にある）が直結するため、名は固定された身分ではなく、何度も手へ戻って意味を持ち直すものとして読める。

原詩の「親」「子」「支援方向」は辞書語義として移植していない。代わりに、手が先に動き、その後から役割の名が追いつく順序を保存した。

### 翻訳による変形

アレム語では子どもの現在相を固定したまま支えの方向だけを変えた。エン語では、役割の名と行為の順序を輪にして、「関係は名前ではなく、手が何をしたかによって更新される」方向へ変形した。

## 翻訳 — ヴェラ語

### 表層詩

> nami sera toku

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `nami sera toku` | 名｜手｜眠る・静止している |

### 表層詩の自然な日本語訳

名は変わらない。  
手の中で、  
静かに眠っている。

### 発声

> namiseratoku → namise / ratoku

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |

### 発声された詩の自然な日本語訳

呼び方では分からなくなった変化を、  
手だけが覚えている。

昨日まで支えられていた手が、  
今日は誰かを支えていることを。

### その言語で起きていること

表層では `nami / sera / toku` が「名／手／眠る」という静止した像を作る。空白を消すと `namiseratoku` となり、発声側では既存語 `namise / ratoku` に再分節される。

表層の「名」は変わらないまま残るが、発声すると名そのものが消え、「手だけが覚えている／声が忘れたもの」になる。原詩で明示された支援方向の反転を、ヴェラ語では「言葉では同じ関係に見えても、身体だけが変化を知っている」という落差へ移した。

### 翻訳による変形

アレム語では新語根が反転そのものを名づける。ヴェラ語では逆に、その変化の名前を消し、手にしか残らない知識として表現する。

## 今回覚えられる語彙

### アレム語 — 新語根

- `p-l-m` — 育てられた者が初めて育てた者を支える側へ回るときに生じる、親子間の支援方向の反転。親子関係の終了や介護一般は指さない
- `pelem` — その反転が近づき、まだ成立していない状態
- `palam` — いま、その支える向きが反転している状態
- `pilim` — 一度起きた反転が身体・手の内部に取り込まれている状態

五相は `palam / pilim / polom / pulum / pelem`。今回本文では `pelem / palam / pilim` を使用した。

### エン語

`ta ku / ku ve / ve li / li ho / ho du / du re / re ma / ma ri / ri se / se no / no ta`。すべて既存の正規語対。

### ヴェラ語

表層：`nami / sera / toku`。発声：`namise / ratoku`。すべて既存語彙。

## 今回覚えられる文法

新文法なし。アレム語の母音相、エン語の環状始点読み、ヴェラ語の再分節を使用する。

## 新しく生じた語彙・規則

### アレム語

新しい正規語根 `p-l-m` を1件追加する。単なる「支える」「介護」「親」の語ではなく、育てた者と育てられた者のあいだで、支援方向が初めて反転する関係的出来事に限定する。

### エン語・ヴェラ語

新語なし。既存語彙のみを使用する。

## 言語史

新しい文法化候補は追加しない。既存慣用 `X do Y` も今回は使用しない。

## 詩的強度の自己検査

- 日本語自然訳だけで「親を支えた日にも、子どもであることは終わらない」という一篇として成立する。
- 中心行「親を支えた日、子どもを卒業したのではない。子どものまま、手の向きだけが変わった」を持つ。
- 直近の死後の仕事継承、昔の重さ、飢えの分配順序と中心像が重複しない。
- 雨・月・鳥・朝・海を中心像に使用していない。
- 新語根 `p-l-m` は物体名ではなく、既存語では切り取りにくい関係の変化を一語根にした。
- アレム語の母音相が `pelem → palam → pilim` と、予感・成立・身体化の距離変化を担う。
- 子ども `kal` は現在相のままなので、「役割方向が変わっても子どもであることは終わらない」という感情が言語構造そのものに出ている。
- エン語・ヴェラ語では、名と手の順序／言葉と身体の記憶差へ別々に変形している。

## 検査

- アレム語：`kal/k-l/a`、`kat/k-t/a`、`pelem/p-l-m/e`、`palam/p-l-m/a`、`pilim/p-l-m/i`、`kit/k-t/i` に分解できる。関係語 `na/ve/vi` は登録済み。
- アレム語：新規語根 `p-l-m` は既存正規語根 `m-r / s-l / n-l / k-t / v-l / l-m / h-r / d-r / n-v / m-s / t-r / r-f / m-n / s-r / k-l / y-r / d-t / g-r-n / k-r-s / f-r-t` と衝突しない。廃止語根 `p-r / m-r(旧夜明け) / s-l(旧子ども)` の再利用でもない。
- アレム語：三子音語根形成 `C1VC2VC3` に従い、`palam / pilim / polom / pulum / pelem` を形成できる。
- エン語：輪の全11境界 `ta ku / ku ve / ve li / li ho / ho du / du re / re ma / ma ri / ri se / se no / no ta` はすべて正規辞書登録済み。未説明語対なし。
- ヴェラ語：`nami + sera + toku = namiseratoku = namise + ratoku`。表層音列と発声音列は文字単位で一致し、境界位置は異なる。使用語はすべて登録済み。
- 新語数：アレム語1語根、エン語0、ヴェラ語0。各言語0〜3件の制約内。
- 同じ語形・語根・語対への無関係な意味追加、旧用法の再利用、未説明語の使用なし。
