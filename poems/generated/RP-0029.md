# 誰の手でもない高さ

- 管理番号：`RP-0029`
- 生成日時：2026-08-30T03:03+09:00
- 原詩言語：エン語
- 題材：共同の井戸綱の同じ位置だけが、何世代もの異なる手に握られて擦り減っている。誰か一人の手形ではないのに、新しく水を汲む者も教わる前からそこを掴む

まず日本語で「井戸綱の同じところだけが白く痩せている。そこに残ったのは誰かの手形ではなく、何人もの手が同じ仕事をした高さだ」という核を置いた。直近の分火、治癒後の保護動作、身体化された帰路から離れ、共同労働が物の摩耗として残し、次の身体を無言で導く位置を扱う。

## 原詩 — エン語

### 輪

> no ta ravel noka ku ve li ho du re ma ri se no

末尾の `no` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `no ta` | 名 |
| `ta ravel` | 共同の道具や綱の同じ位置を、異なる多くの手が反復して握ることで、そこだけが共通の作業高さとして擦り減ること |
| `ravel noka` | その摩耗が特定の一人の手形ではなく、手の入れ替わりを越えて反復された仕事そのものの痕跡になること |
| `noka ku` | 初めてその仕事をする手が、教えられる前から摩耗した位置を触覚で見つけ、同じ場所を掴むこと |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |

`ravel` と `noka` は単独では固定語義を持たない。意味を持つのは `ta ravel / ravel noka / noka ku` の三つの境界だけである。

### `ta` から読む

名の次に現れる手は、一人の所有物としてではなく、共同の綱の同じ位置を何度も握る手として現れる。握られた場所は擦り減り、その痕跡は誰か一人の手形ではなくなる。次の手は声で教わるより先にその摩耗を見つけ、そこから声、家、息、境界、喪失、回帰、光、水面、記憶を経て、再び名へ閉じる。

### `noka` から読む

最初に、新しい手が古い摩耗を見つける。そこから声と家へ進み、仕事をしていた個々の人々が失われても、輪は光と水面と記憶を通って再び名へ戻る。しかし名の直後にはまた共同摩耗が始まり、特定の名は多数の手の反復へ溶けていく。

### 自然な日本語訳

井戸綱の、
同じところだけが白く痩せている。

祖父の手でも、
母の手でも、
いま水を汲む誰かの手でもない。

違う手が来るたび、
同じ高さを掴んだ。

だから綱に残ったのは、
一人ぶんの手形ではなく、
みんなが水を汲んだ高さだった。

初めて綱を握る手も、
教えられる前に、
そこを見つける。

### その言語で起きていること

エン語では「共同体」「摩耗」「継承」を単独語として置かない。既存の `no ta`（名）と `ku ve`（声）の間へ `ta → ravel → noka → ku` を挿入し、名を持つ個人の手が、反復による摩耗を経て、次の手へ無言で位置を渡す三境界として表す。

`ravel noka` では痕跡の所有者を一人に固定しない。続く `noka ku` により、その痕跡は過去の記念ではなく、次の手の動作を実際に決めるものになる。

### 翻訳による変形

アレム語では綱や摩耗を直接訳さず、仕事の残効 `f-r-t` が現在の手から内在する手へ移り、名だけが仕事から離れていく距離関係へ変える。ヴェラ語ではさらに像を削り、表層では「名・手・静止」、発声では「手だけが覚えている／声が忘れたもの」として、無言の継承だけを残す。

## 翻訳 — アレム語

> Farat na kat.  
> Firit vi kit.  
> Nal ra farat.  
> Kat na firit.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Farat na kat.` | 現在相の継承仕事｜接触している｜現在相の手 |
| `Firit vi kit.` | 内在相の継承仕事｜内部にある｜内在相の手 |
| `Nal ra farat.` | 現在相の名｜離れていく｜現在相の継承仕事 |
| `Kat na firit.` | 現在相の手｜接触している｜内在相の継承仕事 |

### 自然な日本語訳

仕事は、いまの手に触れている。

繰り返された仕事は、
やがて手の内側へ入る。

その仕事を始めた名が遠ざかっても、
仕事まで遠ざかるわけではない。

次の手が触れるのは、
名前ではなく、
内側に残ったやり方である。

### その言語で起きていること

既存語根 `f-r-t` は、行為者の名や生が届かなくなった後にも別の手を通して効き続ける仕事の残効を表す。`farat → firit` と現在相から内在相へ移し、仕事そのものが身体内部へ保持されるようにする。

一方、`n-l`（名）は `Nal ra farat` で現在の仕事から離れていく。エン語の「誰の手でもない摩耗」を、アレム語では「名は離れるが、仕事は手へ内在する」という距離の非対称へ翻訳した。新語・新文法は使用しない。

### 翻訳による変形

エン語では物の摩耗が次の手を導く。アレム語では物を消し、仕事が身体の内部に入ることと、名が仕事から離れることへ変える。

## 翻訳 — ヴェラ語

### 表層詩

> nami sera toku

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `nami sera toku` | 名｜手｜眠る・静止している |

### 発声

> namiseratoku → namise / ratoku

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |

### 表層詩の自然な日本語訳

名は、
静かな手の中に置かれている。

誰の名かを言わないまま、
手は同じ場所で止まる。

### 発声された詩の自然な日本語訳

手だけが覚えている。
声が忘れたものを。

誰が最初にそこを掴んだのか、
もう言えなくても、
次の手は同じところへ行く。

### その言語で起きていること

表層 `nami / sera / toku` の連続音列は `namiseratoku`。発声側の既存語 `namise / ratoku` を連結しても同じ `namiseratoku` となり、文字の追加・削除はない。

表層では名と手が静止した像だけを置き、発声すると「手だけが覚えている／声が忘れたもの」へ境界が移る。エン語で井戸綱に残っていた共同労働の痕跡を、ヴェラ語では発声されない身体知へ変形した。新語は使用しない。

### 翻訳による変形

エン語は反復による物の摩耗を三つの関係として保存する。ヴェラ語は摩耗そのものを消し、声から失われても手に残る知識だけを残す。

## 今回覚えられる語彙

### エン語 — 新語対

- `ta ravel` — 共同の道具や綱の同じ位置を、異なる多くの手が反復して握ることで、そこだけが共通の作業高さとして擦り減ること
- `ravel noka` — その摩耗が特定の一人の手形ではなく、手の入れ替わりを越えて反復された仕事そのものの痕跡になること
- `noka ku` — 初めてその仕事をする手が、教えられる前から摩耗した位置を触覚で見つけ、同じ場所を掴むこと

`ravel / noka` 単独には固定語義を与えない。

### アレム語

`farat / firit` — `f-r-t`（別の人の手を通して効き続ける仕事・手入れ・技の残効）の現在相／内在相。`kat / kit` — `k-t`（手）の現在相／内在相。`nal` — `n-l`（名）の現在相。関係語 `na / vi / ra` は既存語彙。

### ヴェラ語

表層：`nami / sera / toku`。発声：`namise / ratoku`。すべて既存語彙。

## 今回覚えられる文法

新文法なし。エン語の環状始点読み、アレム語の既存母音相、ヴェラ語の既存再分節のみを使用する。

## 使用した既存語彙・既存文法

- エン語：`no ta / ku ve / ve li / li ho / ho du / du re / re ma / ma ri / ri se / se no`、環状文と始点読み
- アレム語：`f-r-t / k-t / n-l`、現在相 `a`、内在相 `i`、関係語 `na / vi / ra`
- ヴェラ語：表層 `nami / sera / toku`、発声 `namise / ratoku`、二重分節

## 新しく生じた語彙・規則

### エン語

新しい正規語対を3件追加する。

- `ta ravel`
- `ravel noka`
- `noka ku`

既存の `ta ku`（手の中にある）を廃止せず、RP-0029では `ta → ravel → noka → ku` と境界を展開する。

### アレム語・ヴェラ語

新語なし。既存語彙のみを使用する。

## 言語史

新しい文法化候補は追加しない。エン語の境界展開は今回の語彙的構成に限定する。アレム語の慣用 `X do Y` は使用していない。

## 詩的強度の自己検査

- 日本語自然訳だけで「誰か一人の痕跡ではなく、反復された共同労働が物へ手の高さを刻む」という一篇として成立する。
- 中心像「綱に残ったのは、一人ぶんの手形ではなく、みんなが水を汲んだ高さだった」を持つ。
- 直近の分火、傷の治癒、帰り道を中心像にしていない。
- 雨・月・鳥・朝・記憶・不在を中心像にしていない。
- 新語対3件は井戸や綱そのものの物体名ではなく、反復労働・匿名化・触覚による継承という関係を切り取る。
- エン語固有の「意味は境界にだけある」仕組みが、個人の手から共同の摩耗、次の手へ移る構造に直接寄与している。
- 三言語は、共同摩耗／距離相による仕事の内在／声と手の再分節として異なる変形を持つ。

## 語彙・規則検査

- エン語通常読みの全13語対を照合済み。新規3件以外は既存正規語対。
- `ravel / noka` はリポジトリ内に既存使用がなく、旧用法・同形語との衝突なし。単独語義は付与しない。
- 新規3語対は同一の意味連鎖を構成し、既存の `ta ku` と無関係な多義化を行わない。
- アレム語は正規語根 `f-r-t / k-t / n-l` と関係語 `na / vi / ra` のみを使用し、子音語根と母音相を分離して説明可能。廃止語根なし。
- ヴェラ語の連続音列 `namiseratoku` は表層 `nami / sera / toku` と発声 `namise / ratoku` で文字単位に完全一致し、音の追加・削除なし。
- 未説明語・未登録文法・旧用法の再利用なし。
