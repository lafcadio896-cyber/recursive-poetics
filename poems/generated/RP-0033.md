# 名前は、二度目の身体を持たない

- 管理番号：`RP-0033`
- 生成日時：2026-09-03T03:03+09:00
- 原詩言語：ヴェラ語
- 題材：亡くなった家族と同じ名を生まれた子へ渡すとき、名は家へ戻っても人そのものは戻らない。同じ音が新しい身体へ触れることで、継承と代替の境界が露わになる。

まず日本語で「同じ名を呼んでも、同じ人は帰らない。名だけが新しい身体に触れて、家の中で二度目の生を始める」という核を置いた。直近の死者の衣、休耕、朝の非同期から離れ、誕生・命名・血縁と、名前が身体を越えて継承されるときの非同一性を扱う。

## 原詩 — ヴェラ語

### 表層詩

> mare lino saku  
> nami sera toku  
> vela nori mado

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `mare lino saku` | 光｜水・水面｜触れる |
| `nami sera toku` | 名｜手｜眠る・静止している |
| `vela nori mado` | 声｜家｜残る |

### 表層詩の自然な日本語訳

産湯の水へ、
朝ではない光が触れる。

名を呼ぶ前に、
抱いている手が一度だけ止まる。

やがて声がその名を置き、
家の中に残していく。

名は戻ってきた。
けれど、
腕の中にいるのは
初めてここへ来た身体である。

### 発声

> marelinosaku → mareli / nosaku  
> namiseratoku → namise / ratoku  
> velanorimado → velano / rimado

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `mareli / nosaku` | 誰かが呼ぶ｜消された名前 |
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |
| `velano / rimado` | 家が開いている｜死者の後ろで |

### 発声された詩の自然な日本語訳

誰かが、
もう呼ばれなくなった名を呼ぶ。

手だけが覚えているものを、
声はもう忘れている。

死者の後ろで、
家は新しい者へ開いている。

同じ名が戻っても、
同じ人が戻ったことにはならない。

名は死者を連れ戻さず、
生まれた者のほうへ
意味を作り直していく。

### その言語で起きていること

表層の三行はすべて既存語彙だけで作る。各行の空白を消すと、既存の発声語へ別境界で完全に再分節できる。

- `mare / lino / saku` → `marelinosaku` → `mareli / nosaku`
- `nami / sera / toku` → `namiseratoku` → `namise / ratoku`
- `vela / nori / mado` → `velanorimado` → `velano / rimado`

表層では光、水、手、名、声、家という誕生側の像が並ぶ。発声すると「消された名」「手だけが覚えているもの」「死者の後ろ」が現れる。同じ音列が、新しく生まれた身体と、すでに失われた身体を同時に含む。

ここで再分節は死者の帰還を示さない。むしろ表層の穏やかな命名を発声側が分解し、「名の継承」と「人の代替」は同じではないことを明らかにする。

### 翻訳による変形

アレム語では、同じ `n-l`（名）が現在相・内在相を保つ一方、死者 `d-t` は離行し、新しい子ども `k-l` が手へ接近するという距離の分離へ訳す。エン語では、記憶→名→手→声→家→息→喪失→回帰という既存環を使い、戻ってくるものが人ではなく関係の順序であることを示す。

## 翻訳 — アレム語

> Nal na kal.  
> Nil vi lam.  
> Dot ra nal.  
> Kel ve kat.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Nal na kal.` | 現在相の名｜接触している｜現在相の子ども |
| `Nil vi lam.` | 内在相の名｜内部にある｜現在相の家 |
| `Dot ra nal.` | 離行相の死者｜離れていく｜現在相の名 |
| `Kel ve kat.` | 接近相の子ども｜近づいていく｜現在相の手 |

### 自然な日本語訳

名は、
いまいる子どもへ触れる。

その名は昔から、
家の内側にもあった。

けれど死者は、
名から離れていく。

名が近くに戻ったことと、
死者が戻ることは同じではない。

近づいてくるのは、
新しい子どもの身体である。
手はその身体を受け取る。

### その言語で起きていること

`n-l`（名）は `nal` の現在相として新しい子どもへ触れ、同時に `nil` の内在相として家の内部に残る。一方、`d-t`（死者）は `dot` の離行相で現在の名から遠ざかる。最後に `k-l`（子ども）が `kel` の接近相となり、現在の `kat`（手）へ近づく。

ヴェラ語では同一音列の二重読みによって新生児と死者が重なるが、アレム語では両者の存在距離を意図的に分離する。名は近くにあっても、死者の距離は戻らない。

### 翻訳による変形

ヴェラ語が「同じ音の中に二つの身体史を重ねる」言語なら、アレム語は「同じ名と二つの身体を別々の距離へ置く」言語になる。継承は近接、代替は否定される。

## 翻訳 — エン語

### 輪

> se no ta ku ve li ho du re ma ri se

末尾の `se` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `se no` | 記憶になる |
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |

### `se` から読む

記憶が名になり、名が手の中へ入り、声になり、家に残る。息は扉の後ろで失われるが、輪はそこで終わらず、戻ってきたものが光となって水面に触れ、再び記憶へ閉じる。

### `re` から読む

戻ってくるものから始めると、それは光、水面、記憶、名、手、声、家へ移っていく。やがて息として扉の後ろに置かれ、失われたところで再び「戻る」へ接続する。この始点では、戻るのは個人ではなく、名を介して繰り返される関係の輪に見える。

### 自然な日本語訳

記憶は名になり、
名は手の中へ渡る。

手の中の名は声になり、
声は家に残る。

けれど、
扉の向こうで失われた息まで
同じように戻るわけではない。

戻るのは、
光や水に触れながら
もう一度記憶へ向かう輪である。

同じ名を呼ぶたび、
家は昔へ戻るのではなく、
新しい始点を一つ持つ。

### その言語で起きていること

すべて既存の「帰光」系語対を使用する。`se no → no ta → ta ku → ku ve → ve li` によって記憶から名、手、声、家へ継承が進むが、その後には `li ho → ho du → du re` があり、失われた息は明示的に喪失を通る。

それでも `du re → re ma` によって輪は閉じずに回帰へ進む。ここで戻るものを人そのものと固定せず、始点を変えることで「記憶」「名」「回帰」のどれを先に置くかだけを変える。

### 翻訳による変形

ヴェラ語では同じ音列の中に死者と新生児が重なる。エン語では、同じ輪が何度でも回っても始点だけが変わる。名の反復は同一人物の反復ではなく、関係が新しい始点を得ることへ変わる。

## 詩的強度の自己検査

- 日本語自然訳だけで「同じ名が戻っても、同じ人が戻るわけではない」という一篇として成立する。
- 中心像は、命名の直前に抱く手が一度止まり、古い名が新しい身体へ触れる瞬間。
- 直近の死者の衣、休耕、朝の非同期を中心像にしていない。
- 雨・月・鳥・朝を中心像に使用していない。
- ヴェラ語固有の再分節が、穏やかな誕生命名の表層と、死者の名を背負う発声側の落差へ直接寄与している。
- 三言語は、二重分節／存在距離の分離／環状継承として異なる構造へ変形している。
