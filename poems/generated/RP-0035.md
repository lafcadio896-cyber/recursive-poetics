# 夜を一周した手

- 管理番号：`RP-0035`
- 生成日時：2026-09-05T03:03+09:00
- 原詩言語：エン語
- 題材：眠る前に握っていた手が、夜のあいだに名・声・家・息・喪失・光・水・海・子ども・夜明けを一周し、朝には同じ手へ戻ってくる。眠りを「何も起きない時間」ではなく、失ったものと生きているものが同じ環を通過する時間として読む。

まず日本語で「眠っているあいだ、手は何もしていないように見える。けれど夜を一周したあと、朝に開く同じ手は、眠る前と同じ手ではない」という核を置いた。直近の命名、窓の呼吸、夜明けの非同期から離れ、睡眠そのものを一晩の循環として扱う。

## 原詩 — エン語

### 輪

> lin mo se no ta ku ve li ho du re ma ri se ra tu va ni ke su me yo ka lin

末尾の `lin` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se no` | 記憶になる |
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se ra` | 月 |
| `ra tu` | 沈む |
| `tu va` | 海 |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |
| `ka lin` | 鳥 |

### `lin` から読む

眠りから始めると、月の下で過ごしたものが記憶になり、名になり、手の中へ入る。手から声、家、息へ移り、息は扉の後ろで一度失われる。失われたものは光として戻り、水面、月、海を通り、覚えているものから子ども、開く扉、夜明け、戻る鳥へ進み、再び眠りへ閉じる。

### `re` から読む

「戻ってくる」から始めると、夜は喪失の後に始まる。戻るものは光、水面、月、海、記憶、子ども、扉、夜明け、鳥、眠りを通り、最後に名、手、声、家、息となって扉の後ろへ入り、失われたところで再び回帰へ接続する。

### 自然な日本語訳

眠る前、
手はただ閉じている。

夜のあいだ、
その手の中を
名が通り、声が通り、
家の息が通る。

失われたものも通る。
戻ってきた光も通る。
水面と、沈む月と、
遠い海まで通る。

朝、
子どもが扉を開け、
鳥が戻る。

目を覚ました手は、
眠る前と同じ場所にある。

けれど、
夜を一周してきたことだけは、
手のひらに書かれていない。

### その言語で起きていること

今回は新しい語対を作らず、既存の二つの大きな語彙系列を `mo se → se no` と `ri se → se ra` で横断して一つの環へ編み直した。`se` を境界の分岐点として使うことで、「月の下」がそのまま「記憶になる」方向へ入り、回帰した光が水面へ触れた後には再び「月」へ分岐する。

エン語では単語単独ではなく隣接関係だけが意味を持つため、同じ `se` が前後の相手によって `mo se`（月の下で）、`se no`（記憶になる）、`ri se`（水面に触れる）、`se ra`（月）という異なる境界を成立させる。夜を一周するのは単語ではなく、境界から境界へ受け渡される意味である。

### 翻訳による変形

アレム語ではエン語の長い環を、手・名・声・息・光が現在相から内在相へ移る短い距離変化へ圧縮する。ヴェラ語では表層に「光、水、触れる、名、手、眠り」を置き、発声すると「誰かが呼ぶ／消された名／手だけが覚えている／声が忘れたもの」へ再分節する。

## 翻訳 — アレム語

> Kat na nal.  
> Nil vi kit.  
> Vil vi lim.  
> Hir vi lim.  
> Mir vi kit.  
> Kat na nal.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Kat na nal.` | 現在相の手｜接触している｜現在相の名 |
| `Nil vi kit.` | 内在相の名｜内部にある｜内在相の手 |
| `Vil vi lim.` | 内在相の声｜内部にある｜内在相の家 |
| `Hir vi lim.` | 内在相の息｜内部にある｜内在相の家 |
| `Mir vi kit.` | 内在相の光｜内部にある｜内在相の手 |
| `Kat na nal.` | 現在相の手｜接触している｜現在相の名 |

### 自然な日本語訳

眠る前には、
手と名が触れている。

眠りに入ると、
名は手の内側へ沈み、
声と息は家の内側へ沈む。

光まで、
手の内側へ入ってしまう。

朝になれば、
手と名はまた触れられる現在へ戻る。

同じ手である。
けれど夜のあいだ、
外にあったものをいくつも
内側へ持っていた。

### その言語で起きていること

エン語の長い環を、アレム語では `a → i → a` の距離変化へ圧縮した。`k-t`（手）と `n-l`（名）は現在相で接触して始まり、名・声・息・光が内在相へ移る。最後に手と名だけが現在相へ戻る。

新語根や新文法は使用しない。エン語の「夜を一周する意味」を、アレム語では「外にあるものが眠りのあいだ身体・家の内部へ入る」という存在距離の変化へ翻訳した。

### 翻訳による変形

エン語では夜が多くの関係を一周する。アレム語ではその広がりを捨て、眠りを「現在に触れていたものが内在へ沈み、朝に再び現在へ戻る」運動として読む。

## 翻訳 — ヴェラ語

### 表層詩

> mare lino saku nami sera toku

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `mare lino saku nami sera toku` | 光｜水・水面｜触れる｜名｜手｜眠る |

### 発声

> marelinosakunamiseratoku → mareli / nosaku / namise / ratoku

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `mareli` | 誰かが呼ぶ |
| `nosaku` | 消された名前 |
| `namise` | 手だけが覚えている |
| `ratoku` | 声が忘れたもの |

### 表層詩の自然な日本語訳

光が水へ触れる。

名は手のそばで眠る。

朝になる前の世界は、
まだ何も失っていないように見える。

### 発声された詩の自然な日本語訳

誰かが呼んでいる。

消された名を、
手だけが覚えている。

声のほうは、
もう忘れている。

眠りのあいだに残るものは、
言葉として覚えているものとは限らない。

### その言語で起きていること

表層 `mare / lino / saku / nami / sera / toku` を連結すると `marelinosakunamiseratoku`。発声側 `mareli / nosaku / namise / ratoku` を連結しても同一音列 `marelinosakunamiseratoku` になり、文字・音の追加削除はない。

表層は光、水、名、手、眠りという穏やかな像である。発声すると、名は「消された名」へ変わり、記憶の主体も「声」から「手」へ移る。エン語の長い夜の循環を、ヴェラ語では「声が忘れても身体が覚えている」という一点へ折り畳む。

### 翻訳による変形

エン語では意味が夜を一周して朝へ戻る。ヴェラ語では循環自体を消し、同じ音列の内部に「表面では眠っている名」と「発声すると消されていた名」を重ねる。眠りの時間が、記憶主体のずれとして現れる。
