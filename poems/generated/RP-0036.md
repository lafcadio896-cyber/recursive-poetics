# 理由を失った三つの手順

- 管理番号：`RP-0036`
- 生成日時：2026-09-06T03:03+09:00
- 原詩言語：ヴェラ語
- 題材：伴侶を失った後の二人分の手つき、飢えを越えた後の分配順序、由来を失った畑の刈り残し。理由や名が薄れても、共同体と身体の中では手順だけが正確に反復される。

まず日本語で「理由を説明できなくなっても、手順は理由より長く生きる」という核を置いた。直近の命名、窓の呼吸、睡眠の循環から離れ、個人の癖・共同体の分配・土地の儀礼という異なる尺度を一篇へ並べる。

## 原詩 — ヴェラ語

### 表層詩

> nami seramo mado  
> nami senaru mado  
> nami setaro mado

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `nami seramo mado` | 名｜二人分を当然のように整える手つき｜残る |
| `nami senaru mado` | 名｜自分より先に隣人へ分ける順序｜残る |
| `nami setaro mado` | 名｜由来が忘れられても刈り残す畑の端の一列｜残る |

### 発声

> namiseramomado → namise / ramomado  
> namisenarumado → namise / narumado  
> namisetaromado → namise / taromado

各行で、表層側と発声側の連続音列は完全に一致する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `namise / ramomado` | 手だけが覚えている｜戻らない者の分を用意し続ける日課 |
| `namise / narumado` | 手だけが覚えている｜飢えの後にも隣人の空腹を先に数える身体化した順序 |
| `namise / taromado` | 手だけが覚えている｜理由や受取人の名を失っても同じ場所を収穫から外し続ける反復儀礼 |

### 表層詩の自然な日本語訳

名は、
二人分を整える手つきに残る。

名は、
自分より先に隣人を数える順序に残る。

名は、
刈らない畑の一列に残る。

けれど、
どの名が、どの理由だったのか、
もう同じようには語れない。

### 発声された詩の自然な日本語訳

手だけが覚えている。
戻らない者の分を整えることを。

手だけが覚えている。
飢えが終わった後にも、
隣人から数え始めることを。

手だけが覚えている。
理由を失った畑の端を、
今年も刈らずに残すことを。

理由は消える。
手順は、理由より長く生きる。

### その言語で起きていること

三行すべてが表層では `nami ... mado`（名／…／残る）という同じ枠を持つ。ところが空白を消すと、先頭の `nami` と後続語の冒頭が毎回 `namise`（手だけが覚えている）へ再分節される。表層では「名が残る」三例だったものが、発声側では「名ではなく手が覚える」三例へ変わる。

今回は新語を作らない。`seramo / senaru / setaro` と、それぞれに対応する `ramomado / narumado / taromado` は別々の過去作品で生まれた語彙だが、同じ `nami ... mado → namise / ...mado` 型へ置くことで、個人の喪失・分配習慣・共同体儀礼が「理由より長く残る手順」という共通構造を持つことを初めて示す。新しい同義語を加えるより、既存語彙同士の文化的な関係を発見することを優先した。

### 翻訳による変形

アレム語では三つの具体的手順を一つの `f-r-t`（名や生が届かなくなった後にも別の手を通して効き続ける仕事・手入れ・技の残効）へ圧縮し、慣用化済みの `X do Y` を再使用する。エン語では「隣人から数え始める手」を輪の入口にして、失われた理由が家・息・光・記憶を通って再び同じ手順へ戻る環へ変形する。

## 翻訳 — アレム語

> Farat do nul.  
> Firit vi kit.  
> Firit vi lim.  
> Farat na kat.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Farat do nul.` | 現在相の継承仕事｜後ろに残る（慣用：〜の後にも結果として残る）｜欠如相の名 |
| `Firit vi kit.` | 内在相の継承仕事｜内部にある｜内在相の手 |
| `Firit vi lim.` | 内在相の継承仕事｜内部にある｜内在相の家 |
| `Farat na kat.` | 現在相の継承仕事｜接触している｜現在相の手 |

### 自然な日本語訳

名が呼べなくなったあとも、
仕事の残効は残る。

それは手の内側へ入り、
家の内側へ入り、
また現在の手に触れる。

理由を語れなくても、
手順は現在形で働いている。

### その言語で起きていること

`f-r-t` は、行為者の名や生が届かなくなった後にも、別の人の手を通して効き続ける仕事・手入れ・技の残効を表す既存語根である。`farat`（現在相）から `firit`（内在相）へ移し、手と家の内部に保持されたものが再び現在の手へ触れる構造にした。

`Farat do nul` では既存慣用 `X do Y` を「Yという状態・出来事の後にも、その結果としてXが残る」の方向で再使用する。新語根・新文法は追加しない。

### 翻訳による変形

ヴェラ語では三つの異なる手順が並ぶ。アレム語ではそれらを「名の欠如を通過しても仕事の効力が手と家に内在する」という一つの存在距離へまとめる。何が行われるかより、どこに残っているかが前景化する。

## 翻訳 — エン語

### 輪

> ta pali ku ve li ho du re ma ri se no ta

末尾の `ta` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ta pali` | 食べ物や乏しいものを分けるとき、自分の取り分より先に隣人の取り分へ手を向ける |
| `pali ku` | 飢えや乏しさが終わった後にも、他者から数え始める順序が手の中に残る |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |

### `ta` から読む

手はまず隣人の取り分へ向かい、その順序を手の中へ残す。そこから声、家、息へ進み、扉の後ろで一度失われる。失われたものは光として戻り、水面に触れ、記憶になり、名になって、また「隣人から数え始める手」へ接続する。

### `du` から読む

「失われる」から始めると、理由や名が先に消えたように見える。だが失われたものは光、水面、記憶、名を通って手へ戻り、その手が再び他者から数え始める。こちらの読みでは、名が手順を保存するのではなく、反復された手順が最後に名を作り直すように見える。

### 自然な日本語訳

最初の一つを、
自分ではなく隣へ渡す。

その順番は手に残り、
声になり、家に残り、
息とともに扉の向こうへ行く。

理由は一度、失われる。

それでも何かが戻ってきて、
光に触れ、記憶になり、
あとから名を持つ。

名が手順を残したのか。
手順が名を残したのか。
輪には始点がない。

### その言語で起きていること

新しい語対は追加せず、RP-0021で生まれた `ta pali / pali ku` を既存の「帰光」系列へ接続した。通常読みで使用する全12語対はすべて正規辞書に登録済みである。

`ta` から読めば「手順→喪失→名」、`du` から読めば「喪失→名→手順」となる。同じ環で、文化的手順とそれを説明する名・理由のどちらが先に残るのかを固定しない。

### 翻訳による変形

ヴェラ語では空白の消失によって「名が覚える」から「手が覚える」へ主体が変わる。エン語では主体の変更を使わず、始点の変更によって「名が手順を保存した」のか「手順が名を再生した」のかを反転可能にする。

ヴェラ語では三つの既存再分節型が一篇で並列されたが、これを新文法として登録しない。現時点では詩的な共通構造として観察するに留める。

## 詩的強度の自己検査

- 日本語自然訳だけでも「理由は消える。手順は、理由より長く生きる」という中心行を持つ。
- 直近三篇の中心像である命名、窓の呼吸、睡眠の循環を中心にしていない。
- 個人の生活習慣、飢えを越えた分配、共同体の農耕儀礼という異なる尺度を一つの認識へ束ねている。
- 新語を作らず、既存語彙の再結合によって文化的な共通性を発見することを今回の語彙成長とした。
- ヴェラ語の二重分節は装飾ではなく、「名が残る」から「手が覚える」への認識主体の転換に直接寄与している。
