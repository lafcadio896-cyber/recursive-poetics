# 海は、まだ起きていないことを覚えている

- 管理番号：`RP-0039`
- 生成日時：2026-09-09T03:08+09:00
- 原詩言語：ヴェラ語
- 題材：まだ起きていない出来事を、現在の景色が先に「記憶」の形で受け取ってしまう。表層では海・子ども・月・夜明けが静かな風景として並ぶが、発声すると海が未来を先回りして覚え、夜明けが子どもの行為によって戻る因果へ変わる。

まず日本語で「記憶は過去だけを向いているとは限らない。待っている者にとって、まだ起きていないことは、ときに思い出と同じ輪郭を持つ」という核を置いた。直近の手順、老い、労働継承から離れ、予期と記憶の境界を扱う。

## 原詩 — ヴェラ語

### 表層詩

> ratu vame nika  
> kali mora seyo  
> kesu meyo kali  
> mora seyo ratu

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `ratu vame nika` | 海｜覚えている｜記憶の中の子ども |
| `kali mora seyo` | 子ども｜月｜見る |
| `kesu meyo kali` | 開いた扉｜夜明け｜子ども |
| `mora seyo ratu` | 月｜見る｜海 |

### 発声

> ratuvamenika → ratuva / menika  
> kalimoraseyo → kalimo / raseyo  
> kesumeyokali → kesume / yokali  
> moraseyoratu → morase / yoratu

連続音列の一致を確認する。

- `ratuvamenika` = `ratu + vame + nika` = `ratuva + menika`
- `kalimoraseyo` = `kali + mora + seyo` = `kalimo + raseyo`
- `kesumeyokali` = `kesu + meyo + kali` = `kesume + yokali`
- `moraseyoratu` = `mora + seyo + ratu` = `morase + yoratu`

音の追加・削除はなく、全行で少なくとも一箇所以上、語境界が移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `ratuva / menika` | 海が覚えている｜まだ起きていないこと |
| `kalimo / raseyo` | 昨日が始まる｜扉の後で |
| `kesume / yokali` | 夜明けが戻る｜子どもがそれを開いたために |
| `morase / yoratu` | 月が沈む｜朝が来た後に |

### 表層詩の自然な日本語訳

海は、
記憶の中の子どもを覚えている。

子どもは月を見る。
開いた扉の向こうで、
夜明けはまだ子どものそばにある。

月を見る視線の先に、
海がある。

景色だけを読めば、
何もまだ失われていない。
すべては現在の中に並んでいる。

### 発声された詩の自然な日本語訳

海は覚えている。
まだ起きていないことを。

扉の後ろで、
昨日が始まり直す。

夜明けは戻る。
子どもがそれを開いたために。

そして朝が来たあとで、
月はようやく沈む。

待っている時間には、
未来がときどき
思い出の形をしている。

### その言語で起きていること

表層では `ratu / vame / nika` が「海／覚えている／記憶の中の子ども」という、すでに起きた出来事を保存しているような像を作る。ところが発声すると `ratuva / menika` となり、「海が覚えている／まだ起きていないこと」へ変わる。記憶の向きが過去から未来へ反転する。

続く三行も、表層では子ども・月・開いた扉・夜明け・海という静かな現在景だが、発声側では「昨日が扉の後で始まる」「夜明けが子どもによって戻る」「朝が来た後に月が沈む」と、通常の時間順序がずれる。ヴェラ語の境界移動を、単なる隠し文ではなく、予期が記憶に似る感覚へ使った。

### 翻訳による変形

アレム語では「未来を記憶する」という逆説を直接保存せず、まだ接触していない子どもが海と夜明けの内側に先に存在している、という存在距離へ置き換える。エン語では海・記憶・子ども・扉・夜明け・月を一つの輪へ置き、どこから読み始めるかによって「海が先に覚えていた」のか「子どもが扉を開いたから海が記憶した」のかを固定しない。

## 翻訳 — アレム語

> Sir vi kil.  
> Yer ve kel.  
> Kal na sar.  
> Yir vi kil.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Sir vi kil.` | 内在相の海｜内部にある｜内在相の子ども |
| `Yer ve kel.` | 接近相の夜明け｜近づいていく｜接近相の子ども |
| `Kal na sar.` | 現在相の子ども｜接触している｜現在相の海 |
| `Yir vi kil.` | 内在相の夜明け｜内部にある｜内在相の子ども |

### 自然な日本語訳

海の内側には、
まだ触れていない子どもがいる。

夜明けは、
その子へ近づいていく。

やがて現在の子どもが、
現在の海に触れる。

けれど夜明けは、
そのとき初めて生まれたのではない。

触れる前から、
子どもの内側に
夜明けはあった。

### その言語で起きていること

使用語根は `s-r`（海）、`k-l`（子ども）、`y-r`（夜明け）のみ。母音相は `i`（内在）、`e`（接近）、`a`（現在）、関係語は `vi / ve / na` を用いる。すべて既登録であり、旧用法・廃止語根は使用しない。

ヴェラ語の「まだ起きていないことを海が覚える」を、アレム語では `sir vi kil` として「出来事が成立する前から、海と子どもが互いの内部に位置している」構造へ変えた。未来を時制で表さず、接近相から現在相への移動で示す。

### 翻訳による変形

ヴェラ語では同一音列の再分節によって時間順序が反転する。アレム語では時間の逆転を捨て、`i → e → a → i` の距離移動に置き換える。現在の接触を通った後、夜明けは再び内在へ戻るため、起きた出来事が記憶になると同時に、起きる前から内部にあったものとも読める。

## 翻訳 — エン語

### 輪

> tu va ni ke su me yo ka lin mo se ra tu

末尾の `tu` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `tu va` | 海 |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |

すべて正規辞書に登録済み。未登録の通常語対・一時語対は使用しない。

### `tu` から読む

海が記憶を持ち、その記憶の中から子どもが現れる。子どもが扉を開くと夜明けが戻り、鳥は月の下で眠り、月は最後に海へ沈む。海から始めるため、出来事より先に海が覚えていたように読める。

### `ni` から読む

子どもから始めると、子どもが扉を開き、夜明けが戻り、鳥と月を経て海へ至る。海がそれを覚え、最後に再び子どもへ戻る。この始点では、未来を先に記憶していたのではなく、出来事が一周して記憶になったように見える。

### 自然な日本語訳

海から読めば、
海は先に覚えている。

まだ扉を開いていない子どもを。
まだ戻っていない夜明けを。
まだ沈んでいない月を。

子どもから読めば、
子どもが扉を開き、
夜明けが戻り、
月が沈み、
それから海が覚える。

同じ輪なのに、
記憶が未来を待っていたのか、
未来が記憶になったのかは
始点だけで変わる。

### その言語で起きていること

通常読みの全12隣接語対はすべて既登録。`tu` を始点にすると「海→記憶→子ども」、`ni` を始点にすると「子ども→扉→夜明け→海→記憶」となる。新しい時間標識は作らず、既存の環状構造だけで記憶と予期の順序を反転させる。

### 翻訳による変形

ヴェラ語では同じ音列の二つの分節が「過去の記憶」と「まだ起きていないこと」を重ねる。エン語では音列を変形せず、輪の始点だけを変えることで、記憶が出来事の前にある読みと後にある読みを両立させる。

## 詩的強度の自己検査

- 日本語自然訳だけで「まだ起きていないことが思い出のように感じられる」という中心像が成立する。
- 直近三篇の「理由を失った手順」「老いによる休止点」「親子と労働継承」から題材を離している。
- 雨・鳥・朝・記憶・不在の既出クラスターだけに依存しない。夜明けと記憶は用いるが、中心は「予期が記憶と同じ輪郭を持つ」という時間認識である。
- ヴェラ語の再分節が単なるパズルではなく、「過去を覚える」から「未来を覚える」への感情的・認識的変形を担う。
- 三言語の日本語訳は同文反復ではなく、ヴェラ語＝再分節による時間反転、アレム語＝存在距離、エン語＝始点による因果反転へ分かれている。
