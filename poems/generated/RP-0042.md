# 声は新しい名へ、手は幼い名へ

- 管理番号：`RP-0042`
- 生成日時：2026-09-12T03:02+09:00
- 原詩言語：ヴェラ語
- 題材：成人の名を受けた者が、新しい名には声で返事をできるのに、濡れた面へ触れる手だけは幼い名の形を繰り返す。表層では名・手・静止・光・水・接触が並ぶが、発声すると「手だけが覚えている／声が忘れたもの」「誰かが呼ぶ／消された名前」へ変わり、成長で声と手が別々の速度で名前を移る。

まず日本語で「声はもう新しい名に返事をする。それでも手は、水に触れた瞬間だけ、幼い名の形へ戻る」という核を置いた。直近の未来記憶、葬送の帰路、誕生直後の時間から離れ、成長の儀礼によって一人の身体の中で呼び名の移行速度がずれる瞬間を扱う。

## 原詩 — ヴェラ語

### 表層詩

> nami sera toku  
> mare lino saku  
> nami sera toku

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `nami sera toku` | 名｜手｜静止している |
| `mare lino saku` | 光｜水、水面｜触れる |
| `nami sera toku` | 名｜手｜静止している |

### 発声

> namiseratoku → namise / ratoku  
> marelinosaku → mareli / nosaku  
> namiseratoku → namise / ratoku

連続音列の一致を確認する。

- `namiseratoku` = `nami + sera + toku` = `namise + ratoku`
- `marelinosaku` = `mare + lino + saku` = `mareli + nosaku`
- `namiseratoku` = `nami + sera + toku` = `namise + ratoku`

音の追加・削除はなく、三行すべてで表層側と発声側の語境界が移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |
| `mareli / nosaku` | 誰かが呼ぶ｜消された名前 |
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |

### 表層詩の自然な日本語訳

名は、
手のそばで静まっている。

光が水へ触れる。
その上へ手を置けば、
名もまた水面へ触れる。

声に出さないあいだ、
どちらの名なのかは
まだ決まらない。

名と手は、
同じ場所で静まっている。

### 発声された詩の自然な日本語訳

手だけが覚えている。
声が、もう使わなくなったものを。

誰かが呼ぶ。
消された名前を。

新しい名には、
もう声で返事ができる。

それでも水へ触れた指は、
考えるより先に
幼い名の形をなぞる。

声は新しい名へ行き、
手は幼い名へ戻る。

同じ身体の中で、
名前だけが同じ速さで育たない。

### その言語で起きていること

表層では `nami / sera / toku` が「名／手／静止」を、`mare / lino / saku` が「光／水／触れる」を作る。成人の名を受けた直後、水面や濡れた面へ触れる手が古い字形を無意識に描く情景を、表層側ではまだ断定せず静かな像として置く。

発声すると `namise / ratoku` は「手だけが覚えている／声が忘れたもの」、`mareli / nosaku` は「誰かが呼ぶ／消された名前」になる。声の側では古い呼び名がすでに後退しているのに、手の側では運動として残っている。ヴェラ語の二重分節を、隠された事件の暴露ではなく、一つの身体の中で異なる速度で進む成長へ用いた。

### 翻訳による変形

アレム語では、ヴェラ語の「声と手で移行速度が違う」ことを、同じ `n-l`（名）が接近相・現在相・内在相・離行相へ移る存在距離として再構成する。エン語では、名・手・声・家・息・喪失・回帰・水面・記憶を一つの輪へ置き、名から始めるか声から始めるかで「手が先に名を持つ」のか「声が先に名を更新する」のかを変える。

## 翻訳 — アレム語

> Nel ve vel.  
> Nal na val.  
> Nil vi kit.  
> Nol ra kal.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Nel ve vel.` | 接近相の名｜近づいていく｜接近相の声 |
| `Nal na val.` | 現在相の名｜接触している｜現在相の声 |
| `Nil vi kit.` | 内在相の名｜内部にある｜内在相の手 |
| `Nol ra kal.` | 離行相の名｜離れていく｜現在相の子ども |

### 自然な日本語訳

新しい名が、
新しい声へ近づいてくる。

呼ばれたとき、
名と声は現在で触れ合う。

けれど別の名は、
まだ手の内側にある。

子どもだった自分から
古い名が離れていくあいだも、
手の中では、
それはまだ内在している。

声と手は、
同じ日に同じ距離まで
成長しなくてよい。

### その言語で起きていること

使用語根は `n-l`（名）、`v-l`（声）、`k-t`（手）、`k-l`（子ども）。母音相は `e`（接近）、`a`（現在）、`i`（内在）、`o`（離行）、関係語は `ve / na / vi / ra`。すべて正規辞書に登録済みで、廃止語根・未説明語は使用しない。

`n-l` を `nel → nal → nil → nol` と動かすことで、名を単純に旧名／新名の二項へ分けず、「声には現在として接触したが、手にはまだ内在し、子ども時代からは離れつつある」という複数の距離へ分解した。

### 翻訳による変形

ヴェラ語では同一音列の境界が変わることで、表層の静止した名と手から、発声側の「手だけが覚えているもの」が現れる。アレム語では境界の二重性を捨て、同じ名の語根が `e → a → i → o` と異なる距離を取ることで、声と手の非同期を表す。

## 翻訳 — エン語

### 輪

> no ta ku ve li ho du re ma ri se no

末尾の `no` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |

通常読みで使用する全隣接語対は正規辞書に登録済み。未登録の通常語対・一時語対は使用しない。

### `no` から読む

名は手の中にあり、手から声へ移る。声は家に残り、息となって境界の向こうへ行き、一度失われる。失われたものは戻り、光として水面へ触れ、記憶になって、もう一度名へ戻る。名から始めると、手が先に名を保持し、声がその後を追う輪になる。

### `ku` から読む

声から始めると、声はすでに家の現在へ入り、息・境界・喪失・回帰・光・水面・記憶を経て名へ戻る。最後にその名が手の中へ入るため、こちらでは声のほうが先に新しい名へ到達し、手が一周遅れて受け取るように読める。

### 自然な日本語訳

名から読めば、
名はまず手の中にある。

手から声へ渡り、
声は家へ残る。

いちど失われた呼び名は、
光になって戻り、
水面へ触れ、
記憶になって、
もう一度名になる。

声から読めば、
声のほうが先に進んでいる。

名は輪を一周してから、
最後に手へ届く。

同じ人の中で、
声と手は
同じ名へ同時に着かなくてよい。

### その言語で起きていること

通常読みの全11語対を既存正規語彙だけで構成した。`no` 始点では `no ta → ta ku → ku ve` によって名が手から声へ進む。`ku` 始点では声から一周した後、最後に `no ta → ta ku` が来るため、声が先に更新され、手が遅れて追いつく関係として読める。

### 翻訳による変形

ヴェラ語の二重分節は、同じ音列の内部で「手」と「声」の保持内容を分ける。エン語では語義を増やさず、同じ輪の始点差によって、手が先か声が先かを反転させる。古い名／新しい名というラベルそのものより、更新の順番を保存した翻訳である。

## 詩的強度の自己検査

- 日本語自然訳だけで「声は新しい名に応じるが、手は幼い名の形へ戻る」という中心像が成立する。
- 中心行「声は新しい名へ行き、手は幼い名へ戻る」は単独でも残る。
- 直近三篇の未来記憶・葬送帰路・誕生直後の時間とは題材、身体動作、構造上の焦点が重ならない。
- 雨・月・鳥・朝を中心像に使わない。記憶語は発声辞書の既存語義に含まれるが、作品の中心は成長儀礼と身体内の非同期である。
- ヴェラ語固有の再分節が、秘密情報の暴露ではなく「表層では一つに見える名と身体が、発声すると手と声へ分かれる」という感情的変形に寄与する。
- 三言語の日本語訳は同文反復ではなく、ヴェラ語＝境界分割、アレム語＝存在距離、エン語＝始点による順番の反転へそれぞれ変形している。
