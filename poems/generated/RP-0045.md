# 空の衣に、息だけが先に帰る

- 管理番号：`RP-0045`
- 生成日時：2026-09-15T03:01+09:00
- 原詩言語：ヴェラ語
- 題材：人がいなくなった家に、廊下の光、吊られた衣、残った声だけがある。衣が空気を受けて一瞬だけ身体の輪郭を作るとき、表層では「戻った」ように見えるが、発声すると「身体のない息が先に近づいている」ことが現れる。身体そのものの帰還ではなく、場所が先に人の形を再生してしまう瞬間を扱う。

まず日本語で「人は帰らない。それでも空の衣がふくらむたび、家は息だけを先に帰してしまう」という像を置いた。直近の成人名・播種・成長後の分配順序から離れ、室内の光と衣服の輪郭を中心にした。雨・月・夜明けを中心像に使わず、帰還を『本人が戻ること』ではなく『場所が身体の欠落を先に埋めてしまうこと』として読む。

## 原詩 — ヴェラ語

### 表層詩

> mira seno talu  
> haradume rino  
> vela nori mado

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `mira seno talu` | 明かり｜燃える｜廊下 |
| `haradume rino` | 死者の衣が空気を受け、一瞬だけ失われた身体の輪郭を作る｜戻る |
| `vela nori mado` | 声｜家｜残る |

### 発声

> mirasenotalu → mirase / notalu  
> haradumerino → haradu / merino  
> velanorimado → velano / rimado

連続音列の一致を文字単位で確認する。

- `mira + seno + talu` = `mirasenotalu` = `mirase + notalu`
- `haradume + rino` = `haradumerino` = `haradu + merino`
- `vela + nori + mado` = `velanorimado` = `velano + rimado`

音の追加・削除はなく、三行すべてで表層側と発声側の境界だけが移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `mirase / notalu` | 誰も気づかない｜すでに中に立っている |
| `haradu / merino` | 息が近づく｜どの身体からでもなく |
| `velano / rimado` | 家が開いている｜死者の後ろで |

### 表層詩の自然な日本語訳

廊下では、
明かりだけが燃えている。

吊られた衣がふくらむ。
一瞬だけ肩と胸の形を取り、
戻ってきたように見える。

声はもう聞こえないのに、
家にはまだ、
声のいた場所が残っている。

空の衣に、
息だけが先に帰る。

### 発声された詩の自然な日本語訳

誰も気づかない。
もう、中に立っている。

息が近づいてくる。
けれど、
どの身体からでもない。

家は開いている。
死者の後ろで。

帰ってきたのは人ではない。
人がいないことを知っている家が、
先にその人の形を作ってしまった。

### その言語で起きていること

表層では `mira / seno / talu` が「廊下の明かり」、`haradume / rino` が「衣の中へ一瞬だけ戻る身体の輪郭」、`vela / nori / mado` が「家に残る声」を作る。どれも静かな室内像として読める。

発声すると `mirase / notalu` は「誰も気づかない／すでに中に立っている」、`haradu / merino` は「息が近づく／どの身体からでもなく」、`velano / rimado` は「家が開いている／死者の後ろで」へ変わる。表層で「身体が戻ったように見える」像を、発声側では「身体だけが戻っていない」という否定へ反転した。

### 翻訳による変形

アレム語では、ヴェラ語の表層／発声の落差を、息だけが欠如相から接近相・現在相へ移る一方、死者は内在相に留まるという距離差へ変換する。エン語では身体と衣を捨て、息が「喪失→回帰→光→水面→記憶→名→手→声→家」を一周する環へ変える。

## 翻訳 — アレム語

> Hur do dur.  
> Her ve der.  
> Har na lam.  
> Dit vi lim.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Hur do dur.` | 欠如相の息｜後ろに残る｜欠如相の扉・境界 |
| `Her ve der.` | 接近相の息｜近づいていく｜接近相の扉・境界 |
| `Har na lam.` | 現在相の息｜接触している｜現在相の家 |
| `Dit vi lim.` | 内在相の死者｜内部にある｜内在相の家 |

### 自然な日本語訳

息は、
まだ届かない扉の後ろにある。

やがて息だけが近づき、
境界そのものもこちらへ寄ってくる。

息は現在へ戻り、
家に触れる。

けれど死者は戻らない。
その人は家の内側で、
内在するもののまま残る。

戻ったのは身体ではなく、
身体から離れた呼吸の距離だけだった。

### その言語で起きていること

使用語根は `h-r`（息）、`d-r`（扉・境界）、`l-m`（家）、`d-t`（死者）。`h-r` を `hur → her → har` と欠如相から接近相、現在相へ動かす一方、死者 `dit` は内在相 `i` に留める。関係語は `do / ve / na / vi`。子音語根・母音相・関係語を分離して説明でき、廃止語根は使用しない。

### 翻訳による変形

ヴェラ語では同じ音列の切れ目が変わることで「衣の中に戻る身体」が「身体のない息」へ反転する。アレム語ではその二重性を捨て、息と死者が別々の存在距離を取る。息だけが `u → e → a` と現在へ帰り、死者は `i` の家に留まる。

## 翻訳 — エン語

### 輪

> li ho du re ma ri se no ta ku ve li

末尾の `li` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |

通常読みの全隣接語対は正規辞書に登録済みで、一時語対は使用しない。

### `li` から読む

息は扉の後ろにあり、いちど失われる。失われたものは戻り、光になって水面へ触れ、記憶になり、名になり、手の中へ入る。手から声へ移り、その声は家に残る。身体の帰還ではなく、息が別の関係へ変わりながら家へ戻る環になる。

### `du` から読む

喪失から読み始めると、戻ってきたものはまず光として現れ、水面・記憶・名・手・声・家を通ったあと、最後に息となって扉の後ろへ戻る。こちらでは「家に何かが帰った」のではなく、失われたものを家が一周かけて息へ組み直しているように読める。

### 自然な日本語訳

息は扉の向こうで失われる。

それでも失われたものは、
同じ形では戻らない。

光になり、
水へ触れ、
記憶になり、
名になり、
手と声を通って、
家に残る。

一周したあと、
それをもう一度「息」と呼ぶ。

人が帰ったのではない。
家の中の関係が、
帰還という形を作った。

### その言語で起きていること

`li ho → ho du → du re → re ma` で息は境界の後ろへ行き、失われ、戻る。そこから `ma ri → ri se → se no → no ta → ta ku → ku ve → ve li` と、光・水面・記憶・名・手・声・家を通って環を閉じる。単語単独に意味を置かず、使用した全11語対を正規辞書で照合した。

### 翻訳による変形

ヴェラ語の「身体のない息」という二重分節を、エン語では一つのものが形を保って帰るのではなく、隣接関係を変えながら一周して帰還が成立する構造へ移した。身体と衣は消えるが、「本人ではないものが帰還を成立させる」という中心だけを保存した。
