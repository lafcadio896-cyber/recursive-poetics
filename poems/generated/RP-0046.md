# 手を離れた石は、海の現在になる

- 管理番号：`RP-0046`
- 生成日時：2026-09-16T03:02+09:00
- 原詩言語：アレム語
- 題材：長く掌にあった石を海へ返す。手にとっては「失う」方向へ進む同じ石が、海にとっては「いま触れているもの」になる。一つの移動が、関係する相手によって喪失と現在を同時に作る。

まず日本語で「手を離れた石は、海の現在になる」という一行を置いた。直近の播種・成長した手・空の衣から離れ、所有や記憶ではなく、同じ物体の移動が二者に異なる現在を作る像を選んだ。

## 原詩 — アレム語

> Karas na kat.  
> Kiris vi kit.  
> Koros ra kat.  
> Kurus do kut.  
> Keres ve sar.  
> Karas na sar.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Karas na kat.` | 現在相の石｜接触している｜現在相の手 |
| `Kiris vi kit.` | 内在相の石｜内部にある｜内在相の手 |
| `Koros ra kat.` | 離行相の石｜離れていく｜現在相の手 |
| `Kurus do kut.` | 欠如相の石｜後ろに残る｜欠如相の手 |
| `Keres ve sar.` | 接近相の石｜近づいていく｜現在相の海 |
| `Karas na sar.` | 現在相の石｜接触している｜現在相の海 |

### 自然な日本語訳

掌にあった石を、
海へ返す。

握っていたあいだ、
石は手の内側にいた。

指を開けば、
同じ石が手から遠ざかる。

手にとっては、
もう届かないものになる。

けれど石は消えない。
海へ近づき、
水に触れた瞬間、
もう一度、現在になる。

手を離れた石は、
海の現在になる。

### その言語で起きていること

`k-r-s`（石）を `karas → kiris → koros → kurus → keres → karas` と一周させる。重要なのは、最後の `karas` が最初と同じ現在相でも、関係相手が `kat`（手）から `sar`（海）へ変わっていることにある。母音相の帰還は物体の位置を元へ戻さず、「誰にとって現在か」を更新する。

使用語根は `k-r-s`（石）、`k-t`（手）、`s-r`（海）。関係語は `na / vi / ra / do / ve`。すべて正規辞書に登録済みで、廃止語根・未説明語は使用しない。

### 翻訳による変形

エン語では石そのものを消し、「手の中にあるもの」が声・家・息・喪失・帰還・光・水・記憶・名を通って再び手へ戻る環にする。ヴェラ語では海への接触を表層の「光／水／触れる」に置き、発声すると「呼ぶ者／消された名」へ変わる。アレム語の存在距離が、他二言語では関係の循環と二重分節へ変形する。

## 翻訳 — エン語

### 輪

> ta ku ve li ho du re ma ri se no ta

末尾の `ta` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |

通常読みの全隣接語対は正規辞書に登録済み。一時語対は使用しない。

### `ta` から読む

手の中にあったものは声になり、家に残り、息となって扉の後ろへ行き、失われる。失われたものは戻り、光になって水面へ触れ、記憶と名を経て再び手へ戻る。

### `du` から読む

喪失から始めると、戻るものは光として水へ触れ、記憶と名を経て手へ入る。そこから声、家、息、扉を通り、最後にまた喪失へ着く。失うことと受け取ることが輪の別の始点になる。

### 自然な日本語訳

手の中にあったものは、
手の中だけには留まらない。

声になり、家に残り、
息になって境界を越え、
いちど失われる。

失われたものは、
同じ形では戻らない。
光になって水へ触れ、
記憶と名を通り、
また手へ届く。

離すことは、
輪の外へ捨てることではない。
別の始点へ渡すことだ。

### 翻訳による変形

アレム語では一つの石が手に対して `a → i → o → u`、海に対して `e → a` と距離を変える。エン語では対象の同一性を保存せず、「手から離れたもの」が関係を変えながら一周することで、喪失と受容を同じ環の別位置として読む。

## 翻訳 — ヴェラ語

### 表層詩

> mare lino saku  
> nami sera toku

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `mare lino saku` | 光｜水・水面｜触れる |
| `nami sera toku` | 名｜手｜眠る・静止している |

### 発声

> marelinosaku → mareli / nosaku  
> namiseratoku → namise / ratoku

連続音列を文字単位で照合した。

- `mare + lino + saku` = `marelinosaku` = `mareli + nosaku`
- `nami + sera + toku` = `namiseratoku` = `namise + ratoku`

音の追加・削除はなく、二行とも境界だけが移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `mareli / nosaku` | 誰かが呼ぶ｜消された名前 |
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |

### 表層詩の自然な日本語訳

光が水へ触れる。

名は手の中で静かになる。

離したものの形は見えなくなっても、
水面だけが新しい接触を受け取る。

### 発声された詩の自然な日本語訳

誰かが呼ぶ。
消された名を。

手だけが覚えている。
声が忘れたものを。

離したあとに残るのは、
同じものではなく、
別の側から始まった呼び方だ。

### 翻訳による変形

アレム語の「手にとって欠如、海にとって現在」という非対称を、ヴェラ語では表層と発声の非対称へ移す。表層は水への接触を示すが、発声すると接触は「誰が何を呼び、何を手だけが覚えるか」という関係へ反転する。
