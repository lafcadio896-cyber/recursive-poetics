# 石を置いた人を、道は覚えなくていい

- 管理番号：`RP-0047`
- 生成日時：2026-09-17T03:00+09:00
- 原詩言語：エン語
- 題材：道に迷った者が分岐に石を置き、後から来た者はその人の名も迷いも知らず、ただ石を目印として進める。ある人の不確かさの痕跡が、次の人には確かな方向になる。

まず日本語で「石を置いた人を、道は覚えなくていい」という一行を置いた。直近の親子、衣、海へ返す石から離れ、個人の記憶ではなく、匿名の行為が次の旅人へ機能だけを渡す像を選んだ。

## 原詩 — エン語

### 輪

> tu nemi va ni ke su me yo ka lin mo se ra tu

末尾の `tu` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `tu nemi` | 川、流れ下る水の道 |
| `nemi va` | 海へ入る |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |

通常読みの全隣接語対は正規辞書に登録済み。一時語対は使用しない。

### `tu` から読む

川は海へ入り、海は覚えている。記憶の先に子どもがいて、扉を開く。夜明けは戻り、鳥は眠り、月の下で月が沈む。その沈みから、また川が始まる。

### `ni` から読む

子どもから始めると、先にあるのは開くこと、扉、夜明けである。そこから鳥と月を経て川へ戻り、海が最後に記憶を受け取る。この始点では、記憶は行為の原因ではなく、誰かが通過した後に生じるものになる。

### 自然な日本語訳

分かれ道で、
迷った人が石を一つ置いた。

次に来た人は、
その人の名を知らない。
どちらへ行くか迷ったことも知らない。

ただ、石のある側へ進む。

最初の人にとって、
石は迷いのあとに残ったものだった。

次の人にとって、
石は迷う前からそこにある。

道は、
石を置いた人を覚えなくていい。

一人の不確かさが、
次の一人には
方向として残ればいい。

### その言語で起きていること

エン語の輪では「誰が石を置いたか」を固定語義として登録しない。`va ni`（覚えている）を、`tu` 始点では通過後の記憶として、`ni` 始点では行為の後に最後に到着する記憶として読む。始点を変えることで、同じ関係集合が「先人の経験」と「後続者に最初から与えられた方向」の二つへ分かれる。

新語対として「匿名の道標」を登録すると、既存の `ta ravel / ravel noka / noka ku` がすでに持つ「先人の反復痕跡が後続者を教示なしに導く」という意味領域と重複する危険がある。今回は語義衝突を避け、原詩言語の新語を0件とした。

### 翻訳による変形

アレム語では匿名の継承を、石そのものではなく「身体に内在する帰路感覚」へ移す。ヴェラ語では、表層の「名／手／静止」が、発声すると「手だけが覚えている／声が忘れたもの」へ変わり、作者名が消えても手が残した機能だけが読める構造にする。

## 翻訳 — アレム語

> Karas na talam.  
> Kiris vi tilim.  
> Koros do talam.  
> Keres ve telem.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Karas na talam.` | 現在相の石｜接触｜現在相の身体化された帰路感覚 |
| `Kiris vi tilim.` | 内在相の石｜内部｜内在相の身体化された帰路感覚 |
| `Koros do talam.` | 離行相の石｜後ろに残る｜現在相の身体化された帰路感覚 |
| `Keres ve telem.` | 接近相の石｜近づく｜接近相の身体化された帰路感覚 |

### 自然な日本語訳

石が、道の感覚に触れている。

何度も通るうち、
石は目ではなく身体の内側へ入る。

置いた人が遠ざかっても、
石の位置だけが道の後ろに残る。

次に来る身体へ、
帰る方向が近づいていく。

誰の石だったかではなく、
どちらへ身体を向けられるかが残る。

### その言語で起きていること

使用語根は `k-r-s`（石）と `t-l-m`（目印が失われても身体が次の進路を先取りする帰路感覚）。`karas → kiris → koros → keres` と石の距離を変え、帰路感覚を `talam → tilim → talam → telem` と身体の現在・内在・接近へ移す。関係語 `na / vi / do / ve` はすべて正規辞書に登録済み。`do` は空間的な「後ろに残る」の正規義で用い、結果相への新しい文法化は行わない。

### 翻訳による変形

エン語が始点によって「先人の後」と「後続者の前」を入れ替えるのに対し、アレム語は時間順序を捨て、外部の石が身体内部の進路感覚へ変わる距離を描く。

## 翻訳 — ヴェラ語

### 表層詩

> nami sera toku

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `nami sera toku` | 名｜手｜眠る・静止している |

### 発声

> namiseratoku → namise / ratoku

連続音列を文字単位で照合した。

- 表層：`nami + sera + toku` = `namiseratoku`
- 発声：`namise + ratoku` = `namiseratoku`

音の追加・削除はなく、境界だけが移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `namise` | 手だけが覚えている |
| `ratoku` | 声が忘れたもの |

### 表層詩の自然な日本語訳

名は、
手のそばで静かになる。

置いた者が去れば、
石のそばに名前は残らない。

### 発声された詩の自然な日本語訳

手だけが覚えている。
声が忘れたものを。

誰が置いたかを語れなくても、
置かれた向きだけは
次の身体に読まれる。

### その言語で起きていること

表層 `nami / sera / toku` は「名／手／静止」。発声すると同じ `namiseratoku` が `namise / ratoku` へ再分節され、「手だけが覚えている／声が忘れたもの」になる。表層音列と発声音列は文字単位で完全一致する。

### 翻訳による変形

エン語では記憶の始点が移る。ヴェラ語では記憶の担い手が移り、声が作者を失っても、手の行為だけが別の読みとして残る。
