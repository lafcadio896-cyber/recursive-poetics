# 朝は、子どもの手から入ってくる

- 管理番号：`RP-0048`
- 生成日時：2026-09-18T03:01+09:00
- 原詩言語：ヴェラ語
- 題材：家の中がまだ眠っている時間に、子どもが先に扉を開く。表層では「子ども／月／見る」「開いた扉／夜明け／子ども」という静かな像だが、発声すると「昨日が始まる／扉の後で」「夜明けが戻る／子どもがそれを開いたために」へ変わる。朝を天体の到来ではなく、一人の小さな行為が世界の時間を切り替える瞬間として読む。

まず日本語で「朝は空から来るのではなく、最初に扉を開けた手から家へ入ってくる」という像を置いた。直近の石・道・匿名の継承から離れ、時間の境界を身体の小さな行為が作る場面を選んだ。

## 原詩 — ヴェラ語

### 表層詩

> kali mora seyo  
> kesu meyo kali

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `kali mora seyo` | 子ども｜月｜見る |
| `kesu meyo kali` | 開いた扉｜夜明け｜子ども |

### 発声

> kalimoraseyo → kalimo / raseyo  
> kesumeyokali → kesume / yokali

連続音列を文字単位で照合した。

- `kali + mora + seyo` = `kalimoraseyo` = `kalimo + raseyo`
- `kesu + meyo + kali` = `kesumeyokali` = `kesume + yokali`

音の追加・削除はなく、二行とも語境界だけが移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `kalimo / raseyo` | 昨日が始まる｜扉の後で |
| `kesume / yokali` | 夜明けが戻る｜子どもがそれを開いたために |

### 表層詩の自然な日本語訳

子どもは、まだ残っている月を見る。

開いた扉の向こうに夜明けがあり、
その前に小さな身体が立っている。

家の中はまだ眠っている。
けれど扉だけは、もう朝の側にある。

### 発声された詩の自然な日本語訳

扉の後ろで、昨日が始まる。

夜明けが戻ってくる。
子どもが、それを開いたために。

朝は空から一度に来るのではない。
最初に扉を開けた手から、
家の中へ入ってくる。

### その言語で起きていること

表層では `kali / mora / seyo` が「月を見る子ども」、`kesu / meyo / kali` が「開いた扉・夜明け・子ども」を作る。発声すると同じ音列が `kalimo / raseyo`（昨日が始まる／扉の後で）、`kesume / yokali`（夜明けが戻る／子どもがそれを開いたために）へ変わる。表層では朝はすでに外にあるが、発声側では子どもの行為が夜明けの原因になる。

### 翻訳による変形

アレム語では、夜明けを欠如相から接近相・現在相へ移し、扉と子どもの現在との距離として再構成する。エン語では、扉・夜明け・帰還・鳥・眠り・月・沈降・川・海・記憶・子ども・開く、という既存の輪を用い、始点によって「朝が子どもを起こす」と「子どもが朝を開く」を入れ替える。

## 翻訳 — アレム語

> Yur do dar.  
> Yer ve der.  
> Yar na dar.  
> Kal na dar.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Yur do dar.` | 欠如相の夜明け｜後ろに残る｜現在相の扉 |
| `Yer ve der.` | 接近相の夜明け｜近づく｜接近相の扉 |
| `Yar na dar.` | 現在相の夜明け｜接触する｜現在相の扉 |
| `Kal na dar.` | 現在相の子ども｜接触する｜現在相の扉 |

### 自然な日本語訳

夜明けはまだ届かず、
扉だけが現在にある。

やがて朝が近づくと、
境界も朝の側へ寄っていく。

夜明けが扉へ触れ、
現在になる。

その同じ扉に、
子どもの手も触れている。

朝が来たのか、
手が朝をこちらへ引いたのか。
アレム語では、その二つは同じ接触の現在に重なる。

### その言語で起きていること

使用語根は `y-r`（夜明け）、`d-r`（扉・境界）、`k-l`（子ども）。`y-r` を `yur → yer → yar` と欠如相から接近相、現在相へ動かす。扉は `dar / der / dar`、子どもは `kal`。関係語 `do / ve / na` はすべて正規辞書に登録済み。廃止語根は使用しない。

### 翻訳による変形

ヴェラ語では表層と発声で因果が反転するが、アレム語では因果を断定せず、夜明けと子どもが同じ扉へ接触するまでの存在距離として表す。

## 翻訳 — エン語

### 輪

> su me yo ka lin mo se ra tu nemi va ni ke su

末尾の `su` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `su me` | 扉 |
| `me yo` | 夜明け |
| `yo ka` | 戻る |
| `ka lin` | 鳥 |
| `lin mo` | 眠る |
| `mo se` | 月の下で |
| `se ra` | 月 |
| `ra tu` | 沈む |
| `tu nemi` | 川、流れ下る水の道 |
| `nemi va` | 海へ入る |
| `va ni` | 覚えている |
| `ni ke` | 子ども |
| `ke su` | 開く |

通常読みの全13隣接語対は正規辞書に登録済み。一時語対は使用しない。

### `su` から読む

扉から夜明けが始まり、夜明けは戻る。鳥は眠り、月の下で月が沈む。そこから川が海へ入り、海が覚え、記憶の先に子どもがいて、最後に子どもが扉を開く。

### `ni` から読む

子どもから始めると、子どもが開き、その先に扉と夜明けが生まれる。朝は子どもの行為の後へ置かれ、鳥・月・川・海を一周した最後に記憶へ戻る。

### 自然な日本語訳

扉の向こうに朝がある。
けれど輪をどこから読むかで、
先にあるものは変わる。

扉から読めば、
朝が戻り、世界を巡ったあとで
子どもが扉を開く。

子どもから読めば、
まず開くという行為があり、
その次に扉と朝が来る。

朝は原因にも結果にもなる。
小さな手が輪の始点を選ぶ。

### その言語で起きていること

`su me → me yo → yo ka` で扉・夜明け・帰還を置き、`ni ke → ke su` で子ども・開くを輪の終端に接続する。`su` 始点では朝が先、`ni` 始点では子どもの行為が先になる。使用した全13語対を正規辞書で照合した。

### 翻訳による変形

ヴェラ語の二重分節による因果差を、エン語では同じ語対集合の始点差へ移す。語彙は変えず、読む開始点だけで「朝が来たから扉を開く」と「扉を開いたから朝が来る」の順序を反転する。

### アレム語

### エン語

`su me / me yo / yo ka / ka lin / lin mo / mo se / se ra / ra tu / tu nemi / nemi va / va ni / ni ke / ke su`。すべて既存正規語対。

## 今回覚えられる文法

新文法なし。ヴェラ語は既存の二重分節、アレム語は既存の母音相と関係語、エン語は既存の環状文と始点読みのみを使用する。

## 使用した既存語彙・既存文法

- ヴェラ語：表層 `kali / mora / seyo / kesu / meyo`、発声 `kalimo / raseyo / kesume / yokali`、二重分節

## 新しく生じた語彙・規則
