# 重さは、手が離れたあとで増える

- 管理番号：`RP-0049`
- 生成日時：2026-09-19T03:01+09:00
- 原詩言語：アレム語
- 題材：二人で同じ荷を運んでいる。荷そのものは少しも変わらないのに、一方が手を離した瞬間、残った一人には初めて「全部の重さ」が現れる。重さを物体の性質ではなく、支える身体の数によって遅れて現れる関係として読む。

まず日本語で「重さは、手が離れたあとで増える」という一行を置いた。直近の石・道・朝から離れ、共同労働の最中に起こる、物は変わらないのに身体の側で世界の量が変わる瞬間を中心像とした。

## 原詩 — アレム語

> Makal na kat.  
> Mikil vi kit.  
> Mokol ra kat.  
> Mekel ve kat.  
> Makal na kat.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Makal na kat.` | 現在相の一人分の重さ｜接触｜現在相の手 |
| `Mikil vi kit.` | 内在相の一人分の重さ｜内部｜内在相の手 |
| `Mokol ra kat.` | 離行相の共同支持｜離れていく｜現在相の手 |
| `Mekel ve kat.` | 接近相の一人分の重さ｜近づく｜現在相の手 |
| `Makal na kat.` | 現在相の一人分の重さ｜接触｜現在相の手 |

### 自然な日本語訳

二人で持っていたとき、
荷はただ、手に触れていた。

支えることは身体の内側へ入り、
重さを数える必要もなかった。

片方の手が離れる。
荷は何ひとつ増えていない。

それでも重さは、
残った手へ近づいてくる。

そして同じ荷が、
初めて一人分の重さになる。

重さは、
手が離れたあとで増える。

### その言語で起きていること

新語根 `m-k-l` は「複数で支えていた同じ荷から一つの支持が失われた瞬間、残った担い手へ初めて一人分として現れる重さ」を表す。`makal → mikil → mokol → mekel → makal` と相を移し、最後に同じ現在相へ戻るが、最初の現在は共同支持の中、最後の現在は一人の手に集中した後である。`k-t`（手）と関係語 `na / vi / ra / ve` は既存語彙。

### 翻訳による変形

エン語では「重さ」という対象語を保存せず、手の中にあるものが喪失と帰還を通る輪へ変える。ヴェラ語では共同生活の手順が、発声すると不在者の分まで続ける身体習慣へ変わり、支えが消えた後に残る側の身体へ焦点を移す。

## 翻訳 — エン語

### 輪

> ta ku ve li ho du re ma ri se no ta

末尾の `ta` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |

通常読みの全11隣接語対は正規辞書に登録済み。一時語対は使用しない。

### `ta` から読む

手の中にあるものから始まり、声、家、息を通って失われ、光として戻り、水へ触れ、記憶と名を経てまた手へ戻る。

### `du` から読む

失われるところから始めると、帰還は喪失の後に生じ、最後に手の中のものへ戻る。支えがある状態を原因ではなく、失われた後から読み直されるものとして置ける。

### 自然な日本語訳

手の中にあるものは、
持っているあいだには数えられない。

一つの支えが失われると、
同じものが別の仕方で戻ってくる。

輪を手から読めば、
喪失は途中にある。

喪失から読めば、
手の中にあった軽さのほうが
あとから名を持つ。

### その言語で起きていること

既存の「帰光」系11語対だけを使用した。通常読みの全隣接語対を照合し、未登録の境界はない。原詩の物理的な重さを直接語彙化せず、`ta ku`（手の中にある）と `du re`（失われる）の位置関係を始点差で読む。

### 翻訳による変形

アレム語では重さが身体へ接近する。エン語では、支えを失った後に初めて以前の状態へ「軽さ」という意味が遡って生じる。

## 翻訳 — ヴェラ語

### 表層詩

> nami seramo mado

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `nami seramo mado` | 名｜二人分を当然のように整える手つき｜残る |

### 発声

> namiseramomado → namise / ramomado

連続音列を文字単位で照合した。

- 表層：`nami + seramo + mado` = `namiseramomado`
- 発声：`namise + ramomado` = `namiseramomado`

音の追加・削除はなく、境界だけが移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `namise` | 手だけが覚えている |
| `ramomado` | 戻らない者の分を、戻らないと知った後にも用意し続ける日課 |

### 表層詩の自然な日本語訳

名が残る。
二人分を整える手つきの中に。

一人になったあとにも、
手順だけはすぐには一人分にならない。

### 発声された詩の自然な日本語訳

手だけが覚えている。
戻らない者の分まで、
まだ支える形を。

いなくなった側の重さは消えたのではなく、
残った手の仕事へ移った。

### その言語で起きていること

表層 `nami / seramo / mado` と発声 `namise / ramomado` は既存正規語彙。連続音列 `namiseramomado` は完全一致し、語境界だけが移動する。

### 翻訳による変形

原詩の「共同で持つ荷」を生活の手順へ置き換える。表層では二人分の手つきが残り、発声すると不在を理解した後にも一人が二人分を担う身体習慣になる。

## 今回覚えられる語彙

### アレム語

- `m-k-l` — 二人以上で支えていた同じ荷が、一方の手が離れた瞬間、残った担い手へ「一人分の重さ」として現れる負担の再配分
- `makal / mikil / mokol / mukul / mekel` — 現在／内在／離行／欠如／接近の五相
- `k-t` — 手
- `na / vi / ra / ve` — 接触／内部／離行／接近

### エン語

`ta ku / ku ve / ve li / li ho / ho du / du re / re ma / ma ri / ri se / se no / no ta`。すべて既存正規語対。

### ヴェラ語

表層 `nami / seramo / mado`、発声 `namise / ramomado`。すべて既存正規語彙。

## 今回覚えられる文法

新文法なし。アレム語は既存の母音相と関係語、エン語は環状文と始点読み、ヴェラ語は二重分節のみを使用する。

## 使用した既存語彙・既存文法

- アレム語：`k-t`、母音相 `a / i / o / e`、関係語 `na / vi / ra / ve`
- エン語：上記11語対、環状文、始点読み
- ヴェラ語：表層 `nami / seramo / mado`、発声 `namise / ramomado`、二重分節

## 新しく生じた語彙・規則

- アレム語新語根 `m-k-l`。完全新語根1件。
- エン語・ヴェラ語は新語なし。
- 新文法なし。

`m-k-l` は荷物・重さ・疲労一般を表さない。「共同支持が一つ失われたため、同じ荷が残った担い手へ別の重さとして現れる」という関係に限定する。既存 `p-l-m`（親子の支援方向反転）、`g-l-d`（身体変化による休止点化）、`moravel` 系（成長した子と手に残る昔の重さ）とは語義領域を分離した。

## 言語史

既存候補の慣用化・文法化はなし。新語根 `m-k-l` は語彙としてのみ導入し、文法化候補にはしない。

## 詩的強度の自己検査

- 自然訳だけで「荷は増えていないのに、支える手が減ると重さが増える」という中心像が成立する。
- 直近三作の石・匿名の道標・夜明けから、共同労働と身体的負担へ中心領域を移した。
- アレム語 `m-k-l` は未使用の子音骨格で、既存語根との無関係な意味追加ではない。各語形は三子音語根の正規形成 `C1VC2VC3` に従う。
- エン語の通常読み11語対はすべて正規辞書登録済み。
- ヴェラ語 `namiseramomado` は表層と発声で文字単位に完全一致する。
- 廃止語根、未説明語、一時語対は使用していない。
