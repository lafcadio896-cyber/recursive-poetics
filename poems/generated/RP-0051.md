# 返事は、名前より長く残る

- 管理番号：`RP-0051`
- 生成日時：2026-09-21T03:04+09:00
- 原詩言語：ヴェラ語
- 題材：長く暮らした二人のうち一人が、相手の名をうまく呼べなくなっている。それでも朝になるとカーテンを開け、隣の手へ触れる。言葉の保持と、関係の中で身についた返事・動作の保持が同じ速度では失われないことを、ヴェラ語の表層と発声のずれで読む。

まず日本語で「返事は、名前より長く残る」という一行を置いた。直近三作の夜明け・共同荷重・手放した後の形から離れ、老いの中で言語的な呼称が弱くなっても、共同生活の応答だけが先に消えるとは限らない場面を中心像とした。

## 原詩 — ヴェラ語

### 表層詩

> keno vari sume  
> nami sera toku

### 表層逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `keno vari sume` | 朝｜開く｜カーテン |
| `nami sera toku` | 名｜手｜静止している |

### 発声

> kenovarisume → kenova / risume  
> namiseratoku → namise / ratoku

連続音列を文字単位で照合した。

- `keno + vari + sume` = `kenovarisume` = `kenova + risume`
- `nami + sera + toku` = `namiseratoku` = `namise + ratoku`

音の追加・削除はなく、二行とも境界だけが移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `kenova / risume` | あなたの名は失われた｜それでも返事をする |
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |

### 表層詩の自然な日本語訳

朝になる。
カーテンを開く。

名前は、口まで来ない。
それでも手は、
いつもの場所で静かに隣の手へ触れる。

毎朝していたことは、
誰を呼ぶかより先に
身体の中で朝を始める。

### 発声された詩の自然な日本語訳

あなたの名は失われた。
それでも、返事はする。

手だけが覚えている。
声が忘れたものを。

呼べなくなったことと、
もう応えられないことは
同じではない。

返事はときどき、
名前より長く残る。

### その言語で起きていること

表層では `keno / vari / sume` が「朝、カーテンを開く」、`nami / sera / toku` が「名、手、静止」を作る。発声すると同じ二つの音列が `kenova / risume`（あなたの名は失われた／それでも返事をする）、`namise / ratoku`（手だけが覚えている／声が忘れたもの）へ変わる。表層は共同生活の朝の手順だけを示し、発声側で初めて、その手順が言語的な記憶より長く残っていることが露出する。

新語は導入しない。今回の中心像は既存の `kenova / risume` と `namise / ratoku` の組合せがすでに正確に切り取っており、ここへ「老い」「認知」「長年の伴侶」などを新語として固定すると、既存の「名の喪失」「手の記憶」「声の忘却」へ無関係な医学的・関係的意味を上乗せする危険があるためである。

### 翻訳による変形

アレム語では、名・声・手をそれぞれ離行相・欠如相・内在相へずらし、「同じ人の中で失われる速度が違う」ことを存在距離へ変換する。エン語では、名から始まる輪が手・声・家・息・喪失・帰還を一周して再び名へ戻り、名を始点にするか手を始点にするかで、関係が呼称から始まるのか応答から始まるのかを変える。

## 翻訳 — アレム語

> Nal na val.  
> Nol ra vol.  
> Nul do kat.  
> Vul do kit.  
> Val ve kat.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Nal na val.` | 現在相の名｜接触｜現在相の声 |
| `Nol ra vol.` | 離行相の名｜離れていく｜離行相の声 |
| `Nul do kat.` | 欠如相の名｜後ろに残る｜現在相の手 |
| `Vul do kit.` | 欠如相の声｜後ろに残る｜内在相の手 |
| `Val ve kat.` | 現在相の声｜近づく｜現在相の手 |

### 自然な日本語訳

名と声は、はじめ同じ現在にいる。

やがて名が遠ざかり、
声もその後を離れていく。

呼べない名の後ろに、
手だけはまだ現在として残る。

聞こえない声の後ろにも、
手は身体の内側にある。

そして返事の瞬間だけ、
声はもう一度、
その手の現在へ近づいてくる。

### その言語で起きていること

使用語根は `n-l`（名）、`v-l`（声）、`k-t`（手）の三つだけ。`nal → nol → nul` と名を現在相から離行相・欠如相へ移し、声も `val → vol → vul` と遠ざける。一方、手は `kat / kit` と現在・内在に残す。関係語 `na / ra / do / ve` はすべて既存正規語彙で、未登録語根・接辞は使用していない。

### 翻訳による変形

ヴェラ語では表層と発声の境界移動が「日課」と「名の喪失」を重ねる。アレム語では、名と声が遠ざかっても手だけが現在・内在に残り、返事の瞬間に声が手へ接近するという、三つの存在距離の非同期へ変えた。

## 翻訳 — エン語

### 輪

> no ta ku ve li ho du re ma ri se no

末尾の `no` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |

通常読みの全11隣接語対は正規辞書に登録済み。一時語対は使用しない。

### `no` から読む

名から始めると、名は手の中へ入り、手から声、声から家、家から息へ進む。失われる境界を通っても、戻る・光・接触・記憶を経て、輪は再び名へ帰る。

### `ta` から読む

手から始めると、声と家と息が先にあり、名は最後に来る。呼称が関係を作るのではなく、触れること、返事をすること、同じ家で息をすることの後から「名」が成立する読みになる。

### 自然な日本語訳

名から読めば、
名前が手を呼び、
手が声を呼び、
声が家に残る。

けれど手から読めば、
触れることと、声と、家と、息が先にある。

失われるものを一周して、
最後に名前が来る。

だから名が輪の途中で弱くなっても、
輪そのものがそこで切れるとは限らない。

### その言語で起きていること

同じ11語対の輪を `no` と `ta` から読む。`no` 始点では名が関係の入口だが、`ta` 始点では手・声・家・息が先にあり、名は一周の末尾へ移る。使用した全隣接語対は正規辞書で照合済みで、一時語対・未登録語対はない。

### 翻訳による変形

ヴェラ語の「名前より返事が長く残る」を、エン語では始点の問題へ移す。名前を失うことは輪全体を失うことではなく、関係をどこから読み始めるかが変わることになる。
