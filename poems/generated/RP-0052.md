# 家を出た死者は、声の中へ入る

- 管理番号：`RP-0052`
- 生成日時：2026-09-22T03:01+09:00
- 原詩言語：アレム語
- 題材：亡くなった者を家から送り出した後、その人の姿や声そのものは戻らない。それでも長い時間の後、自分が誰かへ話しかけた瞬間、その人と同じ言い回しが自分の声から出る。帰還ではなく、外から失われたものが別の身体の内側へ場所を変えることを、アレム語の存在距離で読む。

まず日本語で「家を出た死者は、声の中へ入る」という一行を置いた。直近三作の共同荷重・手放した後の形・名前と返事から離れ、葬送後の継承を「記憶している」ではなく、外部から遠ざかったものが別の身体の発話へ内在化する距離変化として扱う。

## 原詩 — アレム語

> Dat na lam.  
> Dot ra lom.  
> Dut do lum.  
> Dit vi vil.  
> Dit vi val.

### 逐語訳

| 原詩 | 逐語訳 |
|---|---|
| `Dat na lam.` | 現在相の死者｜接触｜現在相の家 |
| `Dot ra lom.` | 離行相の死者｜離れていく｜離行相の家 |
| `Dut do lum.` | 欠如相の死者｜後ろに残る｜届かない家 |
| `Dit vi vil.` | 内在相の死者｜内部にある｜内在相の声 |
| `Dit vi val.` | 内在相の死者｜内部にある｜現在相の声 |

### 自然な日本語訳

家にいた死者を、外へ送る。

姿は家から遠ざかり、
やがて、もう触れられないものになる。
家もまた、その人がいた家から離れていく。

それでも何年かして、
誰かへ声をかけたとき、
自分の口から
その人と同じ言い方が出る。

死者が帰ったのではない。
外から失われたものの一部が、
声の内側へ場所を変えた。

### その言語で起きていること

`d-t`（死者）を `dat → dot → dut → dit` と動かし、現在・離行・欠如を通過した後に内在相へ置く。死者そのものを現在へ戻さない点が重要である。家 `l-m` は `lam → lom → lum` と遠ざかり、声 `v-l` は `vil → val` と内在から現在へ現れる。最後まで死者は `dit` のままであり、現在相 `dat` へ復帰しない。したがってこれは幽霊の帰還ではなく、別の身体の発話に内在した言い回しが現在の声として現れる構造になる。

使用した子音語根 `d-t / l-m / v-l`、母音相 `a / o / u / i`、関係語 `na / ra / do / vi` はすべて正規辞書で照合済み。未登録語根・接辞・文法素は使用していない。

新語は導入しない。今回必要な意味は「死者」「家」「声」と、既存の存在距離の組合せで過不足なく表現できる。ここへ「遺伝した口癖」「故人の言い回し」などを新語根として固定すると、既存の `d-t` と `v-l` が母音相によって作れる内在化を重複して語彙化し、語根体系の役割を不必要に狭めるためである。

### 翻訳による変形

エン語では、死者そのものを語彙化せず、声・家・息・喪失・帰還・記憶・名・手を一周させる。ヴェラ語では、表層の静かな「光／水／触れる／名／手」を、発声側で「誰かが呼ぶ／消された名／手が覚える／声が忘れる」へ変え、継承された発話が本人の帰還ではないことを強める。

## 翻訳 — エン語

### 輪

> ve li ho du re ma ri se no ta ku ve

末尾の `ve` は先頭と同一で、輪を閉じる。

### 全隣接語対

| 語対 | 辞書上の意味 |
|---|---|
| `ve li` | 家に残る |
| `li ho` | 息 |
| `ho du` | 扉の後ろにある |
| `du re` | 失われる |
| `re ma` | 戻ってくる |
| `ma ri` | 光 |
| `ri se` | 水面に触れる |
| `se no` | 記憶になる |
| `no ta` | 名 |
| `ta ku` | 手の中にある |
| `ku ve` | 声 |

通常読みの全11隣接語対は正規辞書に登録済み。一時語対は使用しない。

### `ve` から読む

声から読むと、声は家に残り、息となり、扉の後ろへ移り、失われる。その後に戻る・光・接触・記憶・名・手を経て、輪は再び声へ帰る。戻るのは死者そのものではなく、声へ至る関係の輪である。

### `du` から読む

喪失から読むと、戻るものはまず光と接触と記憶を通り、名と手を経て最後に声になる。声は喪失の否定ではなく、喪失を一周した後に成立するものとして読める。

### 自然な日本語訳

声は家に残り、
息は扉の向こうへ行く。

失われたあと、
戻るものは同じ身体ではない。
光に触れ、記憶になり、
名と手を通って、
最後にもう一度、声になる。

### その言語で起きていること

同じ11語対を `ve` と `du` から読む。死者を直接示す語対を追加せず、既存の輪だけで「喪失の後に声へ戻る関係」を作った。使用した全隣接語対は辞書登録済みで、未登録語対・一時語対はない。

### 翻訳による変形

アレム語では死者の存在距離が外部から内部へ移る。エン語では主体を消し、喪失から声までを一周する関係だけを残す。そのため「誰が戻ったか」ではなく「何を経て声が再び成立したか」が前景化する。

## 翻訳 — ヴェラ語

### 表層詩

> mare lino saku  
> nami sera toku

### 表層逐語訳

| 表層語 | 逐語訳 |
|---|---|
| `mare / lino / saku` | 光｜水・水面｜触れる |
| `nami / sera / toku` | 名｜手｜眠る・静止している |

### 発声

> marelinosaku → mareli / nosaku  
> namiseratoku → namise / ratoku

文字単位で照合すると、

- `mare + lino + saku` = `marelinosaku` = `mareli + nosaku`
- `nami + sera + toku` = `namiseratoku` = `namise + ratoku`

音の追加・削除はなく、二行とも境界だけが移動する。

### 発声側の逐語訳

| 発声音列 | 逐語訳 |
|---|---|
| `mareli / nosaku` | 誰かが呼ぶ｜消された名前 |
| `namise / ratoku` | 手だけが覚えている｜声が忘れたもの |

### 自然な日本語訳

光が水へ触れる。
名のそばで、手は静かに止まっている。

声にすると、
誰かが、もう消えた名を呼ぶ。

手だけが覚えている。
声が忘れたものを。

呼んだ者は戻らない。
けれど呼び方だけが、
別の声の中で生きている。

### その言語で起きていること

表層の `mare / lino / saku / nami / sera / toku` は穏やかな接触像だが、連音すると `mareli / nosaku / namise / ratoku` へ再分節される。発声側では「呼ぶ者」「消された名」「手の記憶」「声の忘却」が現れる。二つの音列は完全一致し、既存の表層語・発声語だけを使用する。

### 翻訳による変形

アレム語の内在化を、ヴェラ語では「同じ音列の内部に別の発話が潜んでいる」ことへ変える。死者が戻るのではなく、別の声が同じ音の配置を引き受ける。
